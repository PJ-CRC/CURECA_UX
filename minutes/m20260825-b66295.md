- 소모품 트롤리 Tube 리셋 기준 논의
  ㄴstart 시점 리셋은 제거하고 자동으로 기계가 폐기할 때, 정보 리셋해주고 남은 소모품/시약일 경우 해당 값은 리셋하지 않는 방향으로 정책 변경

- 소모품 트롤리 교체 시 로직
  ㄴ트롤리에서 꺼낸 소모품을 다시 제자리로 돌아가는 로직으로 적용되어 있음. 다른 소모품을 사용하기 위해서는 해당 소모품을 다시 트레이에 옮기고 다른 소모품을 가져다 쓰는 구조
  ㄴ문제점: 트롤리를 교체할 때, 버퍼공간에 있는 소모품을 다시 제자리로 돌려놓지 않고 꺼냈을 경우, 꽉찬 트롤리를 입고했을 경우 버퍼공간에 소모품이 차있어서 사용할 수 없음. 
  ㄴ문제점 관련 개발사와 논의 후 재전달 예정
