[Prep 정책]
- 소모품이 부족해도 검사를 진행할 수 있음 (단, 소모품 트롤리가 없을 경우 검사 진행 불가)
- 부족 상태에 대한 알림을 줄 수 있을지 개발사와 확인 후 전달
- 도킹되어 있는 상태에서 소모품 트롤리 업데이트 가능
- Lock기능을 추가 : 장비와의 데이터 송수신 트리거를 Lock과 Unlock으로 관리
ㄴDX/Prep Door 모두 포함, Run Start 일때만 Auto Lock 

[Material Setup] 
- A 트롤리와 데이터가 물려져 있는 트레이를  B트롤리 기준으로 다시 찍을 경우 Required Quantity는 아래와 같이 표기함
ㄴ 트레이에 장착된 물품이 B 검체 트롤리에 필요하지 않은 소모품일 경우 필요 수량을 - 로 표기함
ㄴ 검체 트롤리 관련없이 필요 항목이 아닌 소모품 추가 적재 가능 (알럿 노출 : 필요 없는 항목인데 적재 할지)
