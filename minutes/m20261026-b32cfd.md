[Assay pack]
- Active/Inactive : 목록에서 적용 여부 Viewer, Detail에서 설정하는 방향으로 진행

[Trolley info]
- 2뎁스 메뉴 레벨로 구성
- 검체 트롤리 정책 변경
ㄴ 모든 검체가 소진된 이후 리셋 진행 (검사 진행 중에는 정보를 물고 있음 / 소켓 단위)
ㄴ 투입 트롤리에서 들고가는 시점이 아닌 회수 트롤리에 도착하는 시점에 리셋
- Tip/Swab UX Case 추가 (실제 명칭까지 포함 예시 : Stool Swab)

[모바일]
- 모바일웹 기준으로 작업할 예정이나 개발사 체크

[기타]
- PCR Setup Starlet 기기 작동 flow 체크
ㄴ 시약을 가지고 간 후 장비 내 거치 > 소켓은 스토리지로 반환 (개발사 확인 필요)
ㄴ 제거 대상에 대한 가이드는 현업 내부 검토 후 추가 예정

[Event History]
- 에러코드 1건 : 시나리오 코드 N건 구조
- Event는 무조건 에러코드 기반으로 생성되며, 시나리오 코드가 있을 수도 있고 없을 수도 있음
- 다만 시나리오 코드는 화면에서 생략하고 effect 항목을 추가하여 시나리오 디스크립션만 노출하되, 하나의 항목에 N건이 줄바꿈처리되어 노출되게 처리
- event popup에도 effect 항목 추가 요청
