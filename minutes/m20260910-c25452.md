[언어셋]
- Instrument
ㄴ All 탭 > Door status, Run time 테이블 항목 제거 (너비 확보 못 할 경우, '사용여부' 컬럼 추가 제거)
ㄴ Waste bin/bottle_1280 > 컬럼값 두 줄처리하는 부분 말줄임'...'으로 표기
ㄴ Main > T-ios와 동일하게 레이아웃 변경 & Door + 아이콘(설정) 표기

-  Event History > Brex 제안안 수용 
- Inventory > Reagent 상세 > 컬럼 값 두 줄 처리
- Login > 비밀번호 변경 팝업, 버튼명 'Save'로 수정

- Quick start / Run
ㄴ Quick start / Run 버튼 > 부가 설명 제거 (영문 수정 필요)
ㄴ Brex 제안안 수용(Run preparation, Protocol, Quick start/run 팝업)

-Test Order
ㄴ Total product > 'STAT samples ' → 'SATA' 으로 수정
ㄴ 검체 상태값 > 색상 & 텍스트로만 구분 (기존 '점' 제거)
ㄴ 그 외, Brex 제안안 수용

- Test Status
ㄴ 'Total batch' 줄바꿈 or 위치 고민 필요
ㄴ 1280 > T-ios와 동일 형태로 수정

- Sample Tracking
ㄴ Samples > 상세 Tray position 수정 & 그 외, Brex 제안안 수용

- Account setting
ㄴ ID 중복체크 > 'Check ID'로 변경

- Protocol
ㄴ 컬럼명 영문 유지 & Action 영문 약어 유지 & On/Off 번역본 유지(넘칠 경우 영문 유지)

[공통]
- 컬럼명 텍스트 긴 경우, 두 줄 처리 진행 (세 줄 이상 말줄임 처리)
