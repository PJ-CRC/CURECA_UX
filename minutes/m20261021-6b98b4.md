[waste bin]
- 유리문 내에 있는 Waste bin의 경우 docking 여부를 노출할 수 있는지 장비 개발사 확인 필요

[Protocol]
-  Standby state setting conditions
ㄴ Name영역 출력 변경(드롭박스 > 고정)
- Operation conditions
ㄴ 순서 조정 및 추가/삭제 기능 버튼 삭제
ㄴ Step / Plate 출력 필요

[Inventory]
- PCR Cold storage 에도 Capacity
- 패키징 단위로 표현 (묶음 단위 또는 개별 단위) : 현재안 유지

[Policy Setting - Cost Setting]
- 소모품 / 시약 탭 구분 
ㄴ 소모품 사용 여부 기능 추가 (디폴트 : 사용 안함)
ㄴ 시약 > Assay pack 기준 로딩
- Analyze Breakpoint
ㄴ cost setting 설정이 안되어 있을 경우, 알럿으로 설정부터 진행하라고 띄우기
- Cost가세팅되지 않았을 경우 통계 미노출 (검사 항목별 사용되는 시약 및 소모품 영향도가 있음)

[회수트롤리]
- 별도의 안내 없이 Run Start 이후 도어를 열었던 히스토리가 없으면 Warnnig단계로 이벤트 노출
