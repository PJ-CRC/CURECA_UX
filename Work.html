구글 시트 연결

시트는 공개하지 않습니다. 시트 편집 권한이 있는 사람이 한 번만 아래처럼 연결하면 모든 작업자 PC에 공유됩니다.

  1. 구글 시트 › 확장 프로그램 › Apps Script를 열고(따로 만든 스크립트도 됨), 연결 스크립트 내용을 붙여 넣고 저장
  2. 프로젝트 설정(톱니) › 스크립트 속성 › 이름 TOKEN, 값은 아무도 모를 긴 글(아래 비밀값과 같게)
  3. 배포 › 새 배포 › 유형 「웹 앱」, 실행 사용자 「나」, 액세스 권한 「모든 사용자」 › 배포 › 권한 허용
  4. 나온 웹 앱 URL을 아래에 넣고 [연결 확인]
