화면을 수정할 때 따르는 작업 순서와 수정 이력 표기 규칙이다. 참고 파일 `Action_Flows.md`(액션별 동작 흐름: 요청 등록 → 적용 문서 확인 → Figma 반영 → 캡처 → 완료 · 변경 이력)의 흐름을 기준으로 정리했다.

> 이 문서는 작업 방식(순서 · 확인 항목 · 산출물 형식)을 정한다. 화면 내용은 화면 정의서 → 정책서 → 기준데이터, 공통 구성 · 컴포넌트는 UX가이드를 따른다.

화면 수정 작업은 아래 순서로 진행한다.

### 작업 순서 요약

1. 반영할 화면 리스트를 정리한다.
2. 리스트의 화면마다 수정할 부분을 정리한다.
3. 수정 작업 후, 수정한 부분에 히스토리를 남긴다.
