# 1. 반영 화면 리스트 정리

작업 전에 반영되어야 하는 화면을 먼저 모은다.

## 1-1. 반영 화면 리스트 작성

반영되어야 하는 화면의 목록을 작성한다.

| 항목 | 내용 |
|---|---|
| 화면 ID | 예: TI-STN-08 |
| 프레임 | 예: TI-STN-08-P (수정 가능 페이지 안의 프레임만) |
| 수정 사유 | 요청 번호 · 정책서 · 회의록 등 근거 |

- 수정 가능 페이지가 아닌 화면은 리스트에 넣지 않고 담당자 확인을 남긴다.
- 정책 · 문서 변경으로 생기는 경우 연관 항목 찾기 결과와 화면설계서 작업대기의 반영 대기 줄을 근거로 한다.
