# 2. 수정 부분 정리

리스트에 올린 화면마다 고칠 곳을 정리한 뒤 작업한다.

## 2-1. 화면별 수정 내용 정리

반영되어야 하는 화면 리스트 안에서 수정되어야 하는 부분을 화면마다 정리한다.

| 항목 | 내용 |
|---|---|
| 화면 | 화면 ID · 프레임 이름 |
| 수정 위치 | 영역 · 레이어(디스크립션인지 화면 요소인지) |
| 지금 | 현재 내용 |
| 바꿀 것 | 수정 후 내용 |
| 근거 | 요청 · 문서 · 항목 |

- 요청과 문서가 어긋나면 요청을 따르고 어긋난 점을 기록한다.
- 정할 수 없는 부분은 임의로 고치지 않고 확인 필요로 남긴다.
