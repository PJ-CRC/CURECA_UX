Workbench 수정 요청을 처리하는 순서, 단계마다 확인할 항목, 산출물(화면 · 캡처 · 기록) 형식을 정리한다. 참고 파일 `CLAUDE.md`의 「Workbench 수정 요청 처리」 · 「캡처」 · 「팀」 규칙을 기준으로 했다.

> 이 문서는 작업 방식(순서 · 확인 항목 · 산출물 형식)을 정한다. 화면 내용은 화면 정의서 → 정책서 → 기준데이터, 공통 구성 · 컴포넌트 · 표기는 UX가이드를 따른다. 문서와 요청이 어긋나면 요청을 따르고 note에 어긋난 점을 적는다.

### 처리 순서 요약

1. 요청 확인 (대상 파일 · 수정 가능 페이지)
2. 「진행 중」으로 변경 (한 요청씩)
3. 작업 기준 문서 확인 (카테고리마다 적용한 문서 하나)
4. Figma 반영
5. 캡처 갱신
6. 변경 이력 기록
7. 「완료」 또는 「보류」 (note 작성)
8. 프로토타입 맞추기 (해당할 때)
