# 3. 처리할 때 지킬 점

## 3-1. 공통 원칙

- 수정 가능 페이지는 파일마다 하나다. 다른 페이지는 읽기만 하고, 요청을 처리할 때마다 그때의 editablePageName으로 확인한다.
- 요청은 한 개씩 「진행 중」으로 바꾸고 끝낸 뒤 다음을 시작한다(토큰 사용량 구간이 겹치지 않게).
- 요청 · 작업의 팀(`team`, 없으면 cureca)대로 일한다: API에 `?team={team}`, 사용량은 `-Team {team}`.
- 해석이 모호하면 임의로 고치지 않고 「보류」와 질문을 남긴다.
- 커밋 · 푸시는 사용자가 요청할 때만 한다.

## 3-2. 처리 후 확인

| 확인 | 내용 |
|---|---|
| 캡처 | 고친 프레임 모두 갱신했는가 |
| 이력 | 변경 이력 항목에 파일명 접두가 있는가 |
| note | 요약 · 고친 곳 · 작업 기준 줄이 있는가 |
| 프로토타입 | 「갱신 필요」 프로토타입에 맞추기 작업을 쌓았는가 |
