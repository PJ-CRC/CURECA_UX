# POL-ACC-003 초기 비밀번호 변경

## 정의

- 초기 비밀번호: 계정을 만들 때 입력하거나 [Generate]로 만든 임시 비밀번호. 관리자가 User Details에서 다시 정해 준 비밀번호도 초기 비밀번호로 봄

## 규칙

1. 계정을 만든 뒤 처음 로그인하면 계정 인증이 성공한 뒤 Reset Initial Password Popup을 보여 줌.
2. 새 비밀번호와 확인 값이 모두 1자 이상일 때 [Save]가 활성화됨.
3. 새 비밀번호가 비밀번호 조건에 맞지 않거나 확인 값과 다르면 안내 문구를 보여 주고 바꾸지 않음.
4. 비밀번호를 바꾸면 로그인 화면으로 돌아가고, 사용자는 새 비밀번호로 다시 로그인함.
5. 초기 비밀번호를 바꾸지 않고 [Cancel]을 누르면 로그인 화면으로 돌아가며, 다음에 로그인하면 Reset Initial Password Popup을 다시 보여 줌.
6. Admin 또는 Service가 Account Setting의 User Details에서 다른 사용자의 비밀번호를 다시 정하면, 그 사용자가 다음에 로그인할 때 Reset Initial Password Popup을 보여 줌.
7. 비밀번호를 다시 정할 때 SMTP가 연동되어 있고 그 사용자의 Email이 있으면 새 비밀번호를 메일로 보냄 (POL-SYS-003).
