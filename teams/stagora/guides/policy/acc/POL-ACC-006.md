# POL-ACC-006 비밀번호 조건

## 정의

- 쓸 수 있는 특수문자: ! @ # $ % ^ & * ( ) _ - + = [ ] { } ; ' : " , . < > ? /

## 규칙

1. 비밀번호 길이는 8자 이상 64자 이하임.
2. 쓸 수 있는 문자는 영문 대문자(A-Z), 영문 소문자(a-z), 숫자(0-9), 특수문자(정의의 목록)임.
3. 비밀번호는 대소문자를 구분함.
4. 영문 대문자, 영문 소문자, 숫자를 각각 1자 이상 넣어야 함. 특수문자는 써도 되지만 필수가 아님.
5. 계정 생성의 [Generate]는 규칙 1~4에 맞는 8자 비밀번호를 만듦 (영문 대문자·소문자·숫자 각 1자 이상).
6. 초기 비밀번호 변경, Profile의 비밀번호 변경, 계정 생성의 임시 비밀번호에 모두 같은 조건을 씀.

## 예외

없음

## 근거

- 정책서_2026.08.28 "비밀번호 생성 조건" (원문 끝의 "3)"은 오타)
- "각 문자 유형을 최소 1자 이상 포함"은 비밀번호 조건이며 여기서 문자 유형은 영문 대문자·소문자·숫자임 (2026-11-02 사용자 확인, 팀원 Q4 해소)
