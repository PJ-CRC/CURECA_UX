# 언어셋 (샘플)

> 상태: **샘플** (2026-11-12). 언어셋을 기준데이터에서 엑셀처럼(하단 시트 탭) 보는 모양을 확인하려고 만든 예시입니다. 문구 · 번역 · 화면 ID는 실제 확정 값이 아닙니다.

화면 문구를 **5개 언어**(한국어 · English · 日本語 · 简体中文 · Deutsch)로 관리합니다. 엑셀의 시트처럼 **종류마다 표(CSV) 하나**이고, 아래 탭으로 오갑니다.

| 시트 | 파일 | 내용 | ID |
| --- | --- | --- | --- |
| A.고유명사 | `proper-nouns.csv` | 서비스 · 제품 · 규격 이름. 번역 기준(번역하지 않는 말 포함) | `LID-PN-001` |
| B.메뉴 | `menus.csv` | GNB · LNB 메뉴 이름 | `LID-MN-001` |
| C.상태값 | `status.csv` | 화면에 보이는 상태 문구(개발 코드값과 짝) | `LID-ST-001` |
| D.버튼 | `buttons.csv` | 공통 버튼 이름 | `LID-BT-001` |
| E.메시지 | `messages.csv` | 알럿 · 토스트 · 확인 팝업 · 빈 화면 문구 | `LID-MS-001` |
| F.번역 요청 | `requests.csv` | 언어셋에 아직 없는 새 문구(번역 필요 → 요청함 → 확정) | 확정 뒤 그 시트의 ID |

## 칸

| 칸 | 내용 |
| --- | --- |
| Language ID | `LID-{시트 약어}-{세 자리}`. 한 번 준 ID는 바꾸지 않는다 |
| 구분 | 시트 안의 묶음(예: GNB · LNB, 공통 · 주문) |
| Type | `noun` 이름 · `menu` 메뉴 · `status` 상태 · `btn` 버튼 · `msg` 메시지 · `title` 제목 |
| 번역 여부 | `번역` · `미번역`(어느 언어에서나 원문 그대로 — 그 언어 칸은 원문을 그대로 적는다) |
| 한국어 · English · 日本語 · 简体中文 · Deutsch | 5개 언어 문구 |
| 사용 화면 | 문구가 쓰인 화면 ID(여러 개면 ` · `로) |
| 비고 | 쓰이는 자리 · 길이 주의 등 |

## 새 문구가 생기면 (예정 흐름)

1. Workbench 요청을 처리하다 언어셋에 없는 문구가 나오면, Claude가 작업규칙의 언어셋 규칙대로 종류를 정해 **F.번역 요청**에 「번역 필요」로 올린다(이미 있으면 사용 화면만 더한다).
2. 번역이 정해지면 그 종류 시트에 새 ID로 옮기고, 번역 요청 줄은 「확정」 + 언어셋 ID로 남긴다.
3. 요청 답변(note)에 「언어셋 › 번역 요청 2개 추가」처럼 적는다.
