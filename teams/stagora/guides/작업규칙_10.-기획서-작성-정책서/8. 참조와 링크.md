# 8. 참조와 링크

참조는 어느 화면의 무엇인지 바로 보이게 쓰고, 다른 페이지나 다른 파일에 있는 대상은 링크를 건다.

## 8-1. 참조 표기

참조 대상별 표기 형식을 정의한다.

| 대상 | 표기 | 예 |
|---|---|---|
| 같은 화면 항목 | `(번호)` | (4.4.2) |
| 다른 화면 항목 | `CID (번호)` | XX-ABC (4.4.2) |
| 다른 화면 | `화면명(CID)` | 상세(XX-ABC-01-P) 팝업 |
| 같은 화면 케이스 | `[Case N. 제목]` | [Case 1. 검색 결과 없음] |
| 다른 화면 케이스 | `CID [Case N. 제목]` | XX-ABC [Case 1. 세션 종료 처리] |
| 공통 프레임 | `[공통] 이름` | [공통] 유효성 메시지 |
| Common UX | `<Common UX (COMM-x-x)>` | <Common UX (COMM-5-s)> |
| 데이터 정의 문서 | 문서명 + 열 · 항목 | 제품목록 N열 |

- 케이스 참조의 제목은 케이스 배너 글자와 똑같이 쓴다.
- 다른 화면의 번호를 CID 없이 쓰지 않는다 (예 : `Header (1) : XX-ABC와 동일` → `XX-ABC (1)`).
- 영문 화면명은 괄호 앞을 한 칸 띄운다 (예 : `Report Preview (XX-ABC-01-P)`).

## 8-2. 링크 (팀 규칙)

참조에 링크를 거는 대상과 방법을 정의한다.

| 구분 | 규칙 |
|---|---|
| 거는 경우 | 같은 파일의 다른 페이지, 또는 다른 파일에 있는 화면 · 케이스를 참조할 때 |
| 링크 대상 | 화면은 디스크립션이 있는 기획서 프레임, 케이스는 케이스 프레임, Common UX는 같은 파일에 있는 해당 COMM 프레임만 (다른 파일의 Common UX는 링크 없이 ID만 씀) |
| 표시 | 링크가 걸린 글자는 밑줄로 표시 |
| 걸지 않는 경우 | 같은 페이지 안의 참조 |
| 여러 번 나올 때 | 한 화면의 여러 항목에서 다른 페이지의 같은 대상을 참조하면, 나오는 곳마다 모두 링크 |
| 파일을 옮길 때 | 프레임을 다른 파일로 옮기면, 원래 파일에 남은 대상을 가리키는 참조에 링크를 다시 건다 |
