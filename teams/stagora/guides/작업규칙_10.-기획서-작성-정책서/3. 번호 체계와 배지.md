# 3. 번호 체계와 배지

디스크립션 번호와 와이어프레임 배지는 반드시 1 : 1로 맞춘다.

## 3-1. 번호와 배지 대응

디스크립션 번호와 와이어프레임 배지의 표기 대응을 정의한다.

| 디스크립션 | 배지 | 쓰임 |
|---|---|---|
| `1` | `1` | 영역 |
| `1.1` | `1-1` | 영역 안의 요소 |
| `1.1.1` | `1-1-1` | 요소를 쪼갠 하위 항목 |
| `*` | 없음 | 화면 공통 |
| `#` | 없음 | 특정 요소가 아닌 화면 전체 규칙 |

## 3-2. 번호 매기기

번호를 매기는 순서와 나누기 · 바꾸기 규칙을 정의한다.

- 번호는 화면 위 → 아래, 왼쪽 → 오른쪽 순서다.
- 케이스 설명 박스는 본 화면의 번호를 그대로 쓴다.
- 한 항목이 약 30줄을 넘거나 성격이 다른 규칙이 섞이면 하위 번호로 나눈다. 나눌 때는 배지도 함께 추가하고, 상위 항목 `참고`에 하위 번호를 적는다.
- 번호를 바꾸면 그 번호를 부르는 다른 화면의 참조도 함께 바꾼다.
