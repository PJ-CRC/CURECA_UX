# 6. UI 문구 표기

UI에 보이는 이름(버튼, 라벨, 컬럼, 값, 메시지, 툴팁)은 화면에 보이는 언어 그대로 쓰고, 설명 문장은 한국어로 쓴다.

## 6-1. 대소문자와 마침표

UI 문구 종류별 대소문자 · 마침표 규칙을 정의한다.

| 대상 | 규칙 (영문 UI) | 예 |
|---|---|---|
| 버튼, 라벨, 컬럼, 메뉴, 화면명 | Title Case | Print Date, Report History |
| 메시지, 툴팁 문장 | 첫 글자만 대문자, 끝에 마침표 | No data available for the selected conditions. |
| 플레이스 홀더 | 마침표 없음 | Please enter a keyword |
| 약어 | 원래 표기 | ID, PDF |

국문 UI는 화면 문구를 그대로 옮기고, 메시지 끝 마침표만 맞춘다.

## 6-2. 대괄호

대괄호를 쓰는 대상과 쓰는 법을 정의한다.

- **대괄호는 누르는 UI에만** 쓰고, 뒤에 종류를 붙인다.
  - `[Save] 버튼`, `[Detail] 탭`, `[All] 라디오`, `[편집] 아이콘`, LNB `[Notice] 메뉴`
- 컬럼명, 라벨, 화면명, 드롭다운 값에는 쓰지 않는다.

## 6-3. 메시지 쓰는 법

메시지 종류별 표기 형식을 정의한다.

| 종류 | 형식 |
|---|---|
| 일반 | `msg : 문장.` |
| 토스트 | `토스트 메시지 노출 - msg : …` |
| 플레이스 홀더 | `Default : 플레이스 홀더 노출` 아래에 `msg : …` |
| 팝업 | `title :`, `msg :` |
| 툴팁 | 툴팁 항목에 `msg : …` |

## 6-4. 말줄임 쓰는 법

말줄임을 쓰는 표준 문장을 정의한다.

- `최대 N줄 노출, 넘을 경우 말줄임 처리`
- `말줄임 처리된 경우, 마우스 호버 시 툴팁으로 전체 표시`

## 6-5. 영문 뒤 괄호

괄호 앞 띄어쓰기를 정의한다.

| 앞 글자 | 규칙 | 예 |
|---|---|---|
| 영문 | 괄호 앞을 한 칸 띄운다 | `Region (지역)` |
| 한글 | 괄호를 붙인다 | `미리보기(XX-ABC-01-P)` |

## 6-6. 약어와 풀네임

약어와 풀네임(Full name)을 함께 보여 주는 법을 정의한다.

| 위치 | 표기 |
|---|---|
| 드롭다운 | `약어 (Full name)` |
| 리스트 | 약어 표시, 마우스 호버 시 Full name |
| 여러 값 연결 | `A + B` (`+` 앞뒤 공백), 순서는 표시 순서와 동일 |
