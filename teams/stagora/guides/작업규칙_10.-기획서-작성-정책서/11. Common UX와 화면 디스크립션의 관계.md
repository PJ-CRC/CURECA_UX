# 11. Common UX와 화면 디스크립션의 관계

같은 규칙은 한 곳에만 두고, 나머지는 참조한다.

## 11-1. 쓰는 곳 나누기

<Common UX>와 화면 디스크립션 중 어디에 쓸지를 정의한다.

| 내용 | 쓰는 곳 |
|---|---|
| 범용 UI 패턴 (팝업, 드롭다운, 페이지네이션, 날짜 · 숫자 표기) | <Common UX> 참조 |
| 화면에서만 보이는 것, 화면별 예외 | 화면 디스크립션 |

- <Common UX>에 있는 규칙은 화면에 다시 쓰지 않고 참조만 한다.
- 화면마다 다른 부분은 화면에 남긴다 (예 : 정렬의 첫 기준).
