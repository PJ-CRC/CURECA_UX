# 5. 문장 작성 규칙

설명은 한국어 명사형으로 끝내고, 한 줄에 규칙 하나만 쓴다. 끝에 마침표를 찍지 않는다 (예 : `~ 표시`, `~ 이동`, `~ 초기화`).

## 5-1. 문장 표현

디스크립션 문장에 쓰는 표현과 쓰임을 정의한다.

| 표현 | 쓰임 | 예 |
|---|---|---|
| `~ 시,` | 동작이 일어날 때 | 선택 시, 상세(XX-ABC-01-P) 팝업 표시 |
| `~일 경우` | 상태 조건 | 조회 결과가 0건일 경우 비활성화 |
| `Default :` | 기본값 | Default : All |
| `→` | 순서가 있는 흐름 | 저장 → 팝업 닫힘 → 토스트 메시지 노출 |
| `:` | 항목과 값, 앞뒤 공백 한 칸 | 등록일 : YYYY-MM-DD |

## 5-2. 동작 용어

디스크립션에 쓰는 동작 용어를 정의한다.

선택(클릭), 마우스 호버, 포커스 아웃, 펼침/접힘, 말줄임 처리, 활성화/비활성화, 노출/미노출, 반응 없음

## 5-3. 쓰지 않는 것

디스크립션에 쓰지 않는 표현과 대신 쓸 표현을 정의한다.

| 쓰지 않는 것 | 대신 |
|---|---|
| `표기` · `쪽` · `클릭` | `표시` · `페이지` · `선택` |
| `ㄴ`으로 하위 내용 잇기 | 들여쓰기 단계 사용 |
| `참고)`처럼 짝이 없는 괄호, 중괄호 `{ }`, 괄호 안의 괄호 | `참고` 단계 사용 |
| 괄호로 붙이는 보충 설명 (같은 값, 조건, 이유) | 한 단계 아래 줄로 내림. 짧은 예시 `(예 : …)`와 단위는 괄호 유지 |
| 콜론을 앞 글자에 붙여 쓰기 (`조건:`) | `조건 :` |
| `~와 동일`만 쓰는 참조 | 핵심 한 줄을 쓰고 참조를 붙임 |

## 5-4. 영문 뒤 조사

영문 뒤에 붙는 조사를 고르는 기준을 정의한다.

- 영문의 마지막 발음 기준으로 붙인다 (예 : `Panel로`, `Lab을`, `Report를`).
- 이름을 바꿀 때 조사도 함께 확인한다.
