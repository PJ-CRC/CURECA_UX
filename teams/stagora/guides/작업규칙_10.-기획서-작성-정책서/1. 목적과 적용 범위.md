# 1. 목적과 적용 범위

이 정책서가 다루는 대상과 다른 문서와의 우선순위, 프로젝트마다 정하는 값을 정의한다.

## 1-0. 적용 대상과 우선순위

이 정책서를 적용하는 대상 · 제외 대상과 다른 문서와의 우선순위를 정의한다.

| 구분 | 내용 |
|---|---|
| 적용 대상 | 화면 프레임의 디스크립션, 케이스 프레임, 문구 표 · 변수 표, `[공통]` 프레임 |
| 제외 | 디자인 시안, 레퍼런스, 프로토타입 화면, 파일 · 페이지 구성과 진행 상태 관리 |
| 우선순위 | 프로젝트의 <Common UX>(조직 단위 UI 규칙)가 있으면 그것을 따르고, 이 정책서는 기획서 작성 방식만 정한다 |
| 새 프로젝트 | 1-1 프로젝트 설정 표만 채우고, 나머지 규칙은 그대로 쓴다 |

## 1-1. 프로젝트 설정

프로젝트마다 다른 값을 정의한다. 이 값은 이 표에만 두고, 본문에서는 이 값을 가리킨다. CID(화면 ID) 규칙은 IA 문서에서 관리하고, 본문 예시의 `XX-ABC`는 CID 자리다.

| 설정 | 정하는 것 |
|---|---|
| Common UX | 공통 UI 문서와 ID 형식 |
| 데이터 정의 문서 : 제품목록 | 제품 · 분석체의 이름, 약어, Full name |
| 데이터 정의 문서 : 정책 | 데이터 정의, 집계 · 계산 기준 |
| 미확정 표시 색 | 미확정 내용의 글자색 |
