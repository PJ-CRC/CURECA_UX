# 7. 자리 표시자(변수)와 형식

`$…$`는 실제 값으로 바뀌는 자리이고, 같은 대상은 문서 전체에서 하나의 변수 이름만 쓴다.

## 7-1. 자리 표시자(변수)

`$…$` 변수의 표기와 쓰는 규칙을 정의한다.

| 표기 | 뜻 | 예 |
|---|---|---|
| `$N$` | 정수 · 건수 | `Printed $N$ times` |
| `$N,NNN$` | 세 자리마다 쉼표 | `Total $N,NNN$` |
| `$NN.N$` | 소수점 첫째 자리 | `$NN.N$%` |
| `$M$` | 개월 수 | `Past $M$ months` |
| `$이름$` | 데이터 값 이름 | `$기관명$`, `$Test Panel$` |
| `$이름 #N$` | 순서가 정해진 값 (값은 변수 표, 10장) | `$항목 유형 #1$`, `$항목 유형 #2$` |

- 한글이 들어간 변수도 값의 이름이다.
- 날짜 · 시간 형식에는 `$`를 붙이지 않는다 (`YYYY-MM-DD`, `$YYYY-MM-DD$` 아님).
- 템플릿 바로 아래에 `예 :` 줄로 실제 예시를 붙인다.
- 같은 대상에 다른 이름을 쓰지 않는다 (예 : `$유형 A$`와 `$항목 유형 #1$`을 섞어 쓰지 않음).

## 7-2. 표시 형식

날짜 · 숫자 · 퍼센트 등 값의 표시 형식을 정의한다.

| 대상 | 형식 |
|---|---|
| 날짜 | YYYY-MM-DD |
| 일시 | YYYY-MM-DD HH:mm:ss |
| 기간 | YYYY-MM-DD ~ YYYY-MM-DD |
| 숫자 | 세 자리마다 쉼표 |
| 퍼센트 | 소수점 첫째 자리 (0% : 0.0%, 0.1% 미만 : <0.1%) |
| 0 | 0 |
| 값 없음 | - |

<Common UX>에 없는 형식이나 화면별 예외만 각 화면 `*` 표시에 쓰고, 나머지는 <Common UX>를 참조한다. 두 문서가 다르면 <Common UX>를 우선하고, <Common UX>가 없으면 이 장의 표가 기준이다.

## 7-3. 계산 값

소수점을 계산해서 보여 주는 값의 표기를 정의한다.

- 소수점을 계산해서 보여 주는 값은 반올림을 함께 쓴다.
- 반올림 : `소수점 둘째 자리에서 반올림`
