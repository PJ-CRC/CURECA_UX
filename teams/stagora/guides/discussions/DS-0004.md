# DS-0004 작업 페이지 안에서 고칠 범위 · 새 화면 자리

## 1. 정할 것
시스템은 Figma 파일마다 작업 페이지 하나만 고치지만, 그 안의 파트(SB · Design) 구분과 최장 언어 화면을 둘 자리 · 이름은 정해지지 않았습니다.

## 2. 논의 전 상태
Claude 시스템 점검(2026-11-17) — 「STAgora 작업규칙」 › 「시스템 확인」 10번에서 올림.
