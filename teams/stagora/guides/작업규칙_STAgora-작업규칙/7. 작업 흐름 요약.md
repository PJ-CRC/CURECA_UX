# 7. 작업 흐름 요약

요청을 받았을 때 판단하는 순서를 한눈에 정리한다.

```
작업 요청
  │
  ├─ 관련 정책이 있는가?
  │    ├─ 있음 ─ 정책에 위배되는가?
  │    │          ├─ 위배 ─→ 작업 중단, 요청자에게 확인 요청
  │    │          └─ 부합 ─→ 정책에 따라 SB 작업
  │    └─ 없음 ─→ SB 작업 + 서비스 전체 영향 여부 모니터링
  │                 └─ 정책 개설 필요 시 사용자에게 별도 알림
  │
  ├─ 정책 변경 요청인가?
  │    └─ 임시 정책 등록 → 전체 확인 → SB 영향도 리스트업 → [승인] → SB 반영
  │       (승인 전 SB는 수정하지 않음)
  │
  ├─ 요청이 논리적 오류 / 공통 UX 위배인가?
  │    └─ 작업 중단, 요청자에게 확인 요청
  │
  ├─ SB 변경으로 UI/문구가 바뀌는가?
  │    └─ 7개 언어 언어셋 반영 필요 여부 확인 및 함께 반영
  │
  └─ 문서 변경 시: 히스토리(버전명, 작업자, 변경 내용) 기록
```
