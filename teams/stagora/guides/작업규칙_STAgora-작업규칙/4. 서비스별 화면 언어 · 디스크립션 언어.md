# 4. 서비스별 화면 언어 · 디스크립션 언어

화면에 표시되는 문구와 디스크립션에 쓰는 언어를 정의한다.

## 4-1. 서비스별 언어

화면(와이어프레임)에 표시되는 UI · 문구는 서비스별 기본 언어로 작성한다.

| 서비스 | 기본 화면 언어 |
|---|---|
| STAgora 임상의 | 한국어 |
| STAgora 검사실 | 영어 |
| GMCS | 영어 |
| Admin | 영어 |
| 초대시스템 | 영어 |
| Secure Uploader | 영어 |

## 4-2. 디스크립션 언어

| 구분 | 규칙 |
|---|---|
| 디스크립션 | **기본 화면 언어와 상관없이 모든 디스크립션은 한국어로 작성한다** |
| 예시 | GMCS(기본 화면 언어: 영어)의 화면 문구는 영어, 해당 화면의 디스크립션은 한국어 |

## 4-3. 언어셋

작업을 대분류 · 중분류로 나누고 사전 확인 · 승인 조건을 정의한다.

## 4-4. 화면 산출물

> 한 요청이 여러 유형에 걸칠 수 있다. 예) 용어 변경 요청: 1(임시 정책 등록) → 4(영향도 리스트업) → 승인 → 2(SB 반영) → 3(언어셋) → 5(히스토리)

## 6. 화면설계서 Figma 수정 시 규칙

작업 이전 내용과 변경된 내용을 반드시 구분할 수 있도록 히스토리를 남긴다. 문서 히스토리 표 기록과 별개로 Figma 화면 위에도 변경 표기를 남긴다.

## 4-5. 작업 순서

변경한 화면 요소 근처에 아래 형식의 표기를 남긴다.

| 항목 | 규칙 |
|---|---|
| 표기 형식 | `[$버전명$/$변경된 내용$]` |
| 텍스트 컬러 | `#ff0000` |
| 폰트 크기 | `12` |
| 위치/크기 조절 | 다른 화면 요소를 가리지 않는 선에서 유동적으로 조절 가능 |
