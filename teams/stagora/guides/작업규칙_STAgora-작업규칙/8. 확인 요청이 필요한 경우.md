# 8. 확인 요청이 필요한 경우

상황별로 AI가 어떻게 행동하는지 한눈에 정리한다.

| 상황 | AI의 행동 |
|---|---|
| 요청이 정책서에 위배됨 | 작업 보류 → 확인 요청 |
| 요청이 논리적으로 맞지 않음 | 작업 보류 → 확인 요청 |
| 요청이 공통 UX에 위배됨 | 작업 보류 → 확인 요청 |
| 관련 정책이 없고 서비스 전체 영향 가능성 있음 | SB 작업 진행 + 정책 개설 필요성 별도 안내 |
| 공통 자료(정책서 등) 변경 요청 | 바로 수정하지 않고 임시 정책 등록 → 확인 → SB 영향도 리스트 → [승인] 후 SB 반영 |
| SB 변경으로 UI/문구가 바뀜 | 언어셋(7개 언어) 변경 사항 함께 반영 |
