# 용어 통일 검토

> 상태: 초안 작성 전.

Claude가 용어집 기준으로 표현을 검토하고 바꾸는 순서를 정합니다.

## 담을 내용

- 검토 6단계: 읽기 → 찾기 → 바꾸기 → 묻기 → 검사 → 보고
- 치환 목록과 질문 목록 형식
- 화면 라벨 변경 시 변경 예정 표시
- 대화와 문서의 구분: 요청에서는 편한 표현(예: 유저타입)을 받아들이되 뜻이 불확실하면 작업 전에 묻고, 문서에는 표준어만 씀 (`glossary/glossary.md` "대화와 문서")
- 대화에서 새로 나온 표현은 뜻을 확인한 뒤 용어집의 "쓰지 않는 표현"에 추가
