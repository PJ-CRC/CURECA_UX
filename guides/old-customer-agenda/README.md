# 고객 논의 대상

고객이 정해야 하는데 아직 정의되지 않은 항목을 모읍니다. 고객 미팅 안건을 만들 때 이 목록과, 임시 정책 중 "임시 적용"·"고객 확인 요청" 항목(`old-provisional/`)을 함께 씁니다.

- 목록: [agenda.md](agenda.md). 항목 ID는 `CA-0001` (네 자리 일련번호, 쓴 번호는 다시 쓰지 않음)
- 임시로 화면에 적용한 것은 임시 정책(PV)으로 등록하고 여기에는 넣지 않습니다. 화면에 적용하지 않고 답을 기다리는 것만 여기에 둡니다.
- 상태: 논의 전 → 논의 중 → 결정 (결정 내용과 근거를 적고, 정책에 반영하면 정책 ID를 적음)
- 결정된 항목도 지우지 않습니다.
