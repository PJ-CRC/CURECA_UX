## 양식

```text
[UX → UI 전달] {메뉴} · {작업 기록 제목의 요청 한 줄 요약}
UX 확정: {날짜} ({근거: 고객 UX 검토 N차 / 내부 검토 반영})
요청자: {이름}

■ 1. 작업 범위 (UI 작업 대상)
• {CID T} / {CID L} · {화면 이름} · {수정 / 신규 / 다시 그리기 (글자만)} · v{Ver} · {무엇을 한 줄} · {Figma 링크}
UI 작업 대상 아님 (참고)
• 요건 {N} · {요건 한 줄} · {이유}

■ 2. 변경 정보 (화면마다)
{화면 이름} ({CID T} / {CID L})
• 추가: {요소} #{디스크립션 번호}
• 수정: {요소} ({변경 전} → {변경 후}) #{번호}
• 제거: {요소} #{번호}

■ 3. 언어셋 (바뀐 화면 표기 글자)
• {신규 / 변경 / 제거} · {CID} #{번호} · {English (변경은 변경 전 → 변경 후)} · {Language ID 또는 "새 ID"} · 가장 긴 언어 {언어}: {그 번역 글자}
7개 언어 전체 번역: {첨부 파일 이름 또는 언어셋 링크}
검증 상태: AI 번역 {N}줄 (법인 검토 전, 바뀔 수 있음)

■ 4. 새로 그린 요소 (공통 UX에 없어 UX에서 새로 그림)
• {요소 이름} ({종류}) · {CID} #{번호} · {신규로 만듦 / 후보 ID / 기존 화면에서 따옴} · {Figma 링크}

■ 5. 상태별 화면 (상태마다 모습이 다른 것)
• {CID} Case {N} · {제목} · {조건}

■ 6. 알럿 · 토스트 (새로 생기거나 바뀐 것)
• {CID} #{번호} · {종류} · {코드} · {언제}
```
