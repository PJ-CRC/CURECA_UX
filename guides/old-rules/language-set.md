# 다국어

> 상태: 초안 v0.2 (2026-10-29). 큰 흐름만 잡은 초안입니다. **2026-11-04:** 언어셋 관리를 저장소로 옮기고 관리 주체를 Claude로 하기로 함. 지금까지의 언어셋 v0.03을 초안 원본으로 받음(`language-set/analysis-v0.03.md`). 관리 방식과 이 문서 개정은 화면설계서 규칙 정리 뒤 진행(`background/todo.md` "언어셋 관리 체계"). 그때까지 2절의 "읽기만 함"은 그대로 둡니다.

화면은 7개 언어로 서비스합니다(2026-11-04 독일어 포함으로 정정). UX 설계는 영어로 하고, UI 작업자가 언어별 길이에 맞춰 디자인할 수 있도록 가장 긴 언어 기준의 화면을 함께 만듭니다.

## 1. 언어

| 구분 | 언어 |
| --- | --- |
| 설계 기준 | 영어 |
| 제공 언어 | 영어, 한국어, 독일어, 포르투갈어, 스페인어, 이탈리아어, 프랑스어 (7개). 한국어는 언어셋에 11월 말 추가 예정 |

## 2. 언어셋

- 7개 언어 문구는 언어셋 문서(엑셀)로 관리합니다. 문구마다 ID가 있고, 고유명사도 따로 관리합니다.
- 언어셋은 언어셋 담당자가 관리합니다. 앞으로는 언어셋 문서도 Claude가 관리하도록 바꿀 예정이며, 그 관리 체계는 담당자가 정해 이 문서에 반영합니다.
- **언어셋은 내부 논의 대상이 아닙니다.** 영어 문구는 고객사 컨펌으로 확정되고, 나머지 6개 언어 번역도 고객사를 통해 받습니다. 그래서 언어셋은 공통 자료의 주간 미팅 합의(`old-rules/change-flow.md`)를 거치지 않습니다.
- UX 작업에서 Claude는 언어셋을 읽기만 하고 고치지 않습니다. 번역도 만들어내지 않습니다. 새 문구는 5절의 번역 요청 목록에 올립니다.

## 3. 화면 산출물

화면 하나를 설계하면 두 가지 화면을 만듭니다.

| 화면 | 내용 | 보는 사람 |
| --- | --- | --- |
| 영어 화면 | 영어로 작성한 UX 화면 | 고객 (리뷰·컨펌) |
| 최장 언어 화면 | 같은 화면의 문구 자리마다 7개 언어 중 가장 긴 표현을 넣은 화면. 문구마다 가장 긴 언어가 다를 수 있어 여러 언어가 섞여 보임 | UI 디자이너 (언어 길이 참고) |

## 4. 작업 순서

화면을 설계하거나 문구를 바꿀 때 Claude는 다음 순서로 작업합니다.

1. **영어로 설계:** 화면의 라벨, 버튼, 메시지를 영어로 작성합니다. 용어집의 표준어를 씁니다.
2. **문구 찾기:** 화면의 문구마다 언어셋에서 같은 문구와 그 ID를 찾습니다.
3. **7개 언어 가져오기:** 찾은 문구의 7개 언어 번역을 가져옵니다. 고유명사는 언어셋의 고유명사 기준을 따릅니다.
4. **가장 긴 표현 찾기:** 문구마다 7개 언어 중 가장 긴 표현을 고릅니다.
5. **최장 언어 화면 만들기:** 영어 화면의 각 문구를 가장 긴 표현으로 바꾼 화면을 만들고, 레이아웃(버튼 폭, 줄바꿈, 말줄임)에 문제가 생기는 곳을 표시합니다.
6. **보고:** 문구별 언어셋 ID, 가장 긴 언어와 표현, 이번 작업에서 번역 요청 목록에 새로 올린 문구를 결과에 붙입니다.

## 5. 새 문구와 번역 요청

언어셋에 없는 영어 문구가 생기면, 묻지 않고 번역 요청 목록에 올리고 알립니다. 모인 목록은 고객사에 보내 6개 언어 번역을 받고, 고객사가 확인해 주면 확정됩니다.

### 번역 요청 목록

`language-set/translation-requests.csv` 한 파일에 문구 하나를 한 줄로 둡니다.

| 칸 | 내용 |
| --- | --- |
| 영어 문구 | 화면에 쓰인 영어 문구 그대로 |
| 사용 위치 | 문구가 쓰인 CID (여러 개면 모두) |
| 추가일 | 목록에 올린 날 |
| 추가한 사람 | 작업을 요청한 팀원 |
| 상태 | 번역 필요 / 고객사 요청함 / 확정 |
| 고객사 요청일 | 고객사에 보낸 날 |
| 확정일 | 고객사가 확인해 준 날 |
| 언어셋 ID | 확정 후 언어셋에 들어간 ID |

### 흐름

1. **추가:** 작업 중 언어셋에도, 번역 요청 목록에도 없는 영어 문구가 나오면 Claude가 "번역 필요" 상태로 목록에 올립니다. 이미 목록에 있으면 사용 위치만 더합니다.
2. **알림:** 작업 결과에 "번역 요청 목록에 새로 올린 문구"를 적어 알립니다.
3. **표시:** 최장 언어 화면에서는 그 문구를 영어로 두고 "번역 대기"로 표시합니다.
4. **정리:** 팀원이 요청하면 Claude가 "번역 필요" 문구를 뽑아 고객사에 보낼 목록을 만듭니다. 영어 문구와 6개 언어(한국어, 독일어, 포르투갈어, 스페인어, 이탈리아어, 프랑스어) 빈칸, 사용 화면으로 구성합니다. 보낸 문구는 "고객사 요청함"으로 바꿉니다.
5. **확정:** 고객사가 번역을 확인해 주면 "확정"으로 바꾸고 언어셋에 반영합니다. 반영 방법은 언어셋 관리 체계를 따릅니다.

영어 문구 자체는 화면의 고객 컨펌 때 함께 확인됩니다.
