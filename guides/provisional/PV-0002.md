# PV-0002 Account Setting 목록과 삭제·수정 범위

| 항목 | 내용 |
| --- | --- |
| 상태 | 승인 |
| 바꾸는 정책 | POL-ACC-001 추가, POL-ACC-002 추가 (Account Setting 목록 범위와 삭제·수정 범위) |
| 작성자 | 서보경 |
| 등록일 | 2026-11-02 |
| 기준 공통 규칙 버전 | 없음 (공통 규칙 버전 태그 전에 등록) |
| 고객 확인 | 기다림 (CA-0003) |

## 바꾸는 내용

1. User Type이 Admin인 사용자가 Account Setting을 보면 Service 계정은 목록에서 빼고 보여 줌.
2. User Type이 Service인 사용자가 보면 모든 계정을 보여 줌.
3. Service 계정은 최소 1개를 남겨야 하며, 모든 Service 계정을 지울 수 없음.
4. Admin은 다른 Admin 계정을 수정할 수 있음.
5. 자기 계정은 지울 수 없음.
6. 3·5에 걸리는 삭제를 시도하면 Alert_047을 보여 주고 지우지 않음.

## 이유와 근거

- 2026-11-02 사용자 결정. 고객과 확인할 내용이라 임시 정책으로 둠
- 화면(TI-STN-05)은 목록 범위를 "Admin이 생성한 모든 계정", User Type 필터를 All·Admin·User로만 적었고 삭제 제한이 없음

- 반영 대기 줄 (2026-11-05 승인 때 정리): TI-STN-05-R04 (목록 범위 · User Type 표시 값), TI-STN-05-R05 (User Type 드롭다운 Service 항목, 확인 필요), TI-STN-05-R06 (자기 계정 · 마지막 Service 계정 삭제 시 Alert_047, 확인 필요), TI-STN-05-03-P-R01 (Admin이 다른 Admin 계정 수정), TI-STN-05-03-P-R03 (확인 필요: Service 계정 상세의 User Type 표시, 수정으로 Service 계정이 0개가 되는 경우). 앞 줄 TI-STN-05-R02 · R03은 R04 · R05 · R06로 대체해 제외
