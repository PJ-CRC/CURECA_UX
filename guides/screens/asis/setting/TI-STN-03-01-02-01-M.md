### 디스크립션 (원문)

#### 1. 검체 항목 정보

- 노출 : [TI-STN-03-01-02] 화면에서 선택한 검체 항목 정보 노출
- 출력 : 검체 type, 편집자 ID, 편집 일자/시간

#### 2. Process guide

- Full case 참고 → Case 정의 바로가기

#### 3. Protocol setting

- 디폴트 : 상위 프로토콜에 따른 하위 검체 항목 상세 값 노출
- 목록 Min/Max 값 정의
- 최소 : 1개
- 최대 : N개 (수정 필요)
- 관련 항목 정의 Case 참고 → Case 정의 바로가기
- 검체별 디폴트 Setting 값 → ‘검체 배치롤 엑셀 파일’ 참고
- 3-1 라디오 버튼
- 디폴트 : 미선택
- 선택 시 → 해당 버튼 활성화
- 3-2 순서 변경 버튼
- [∧] 버튼
- 디폴트 : 비활성화
- 활성화 조건 : 아래 2가지 조건 만족 시, 활성화
- ㄴ 조건 1) 3-1 버튼 선택 시
- ㄴ 조건 2) 최상위(No.1) 항목 外, 선택 시
- 선택 시 → 해당 항목 한 단계 위(Index + 1) 이동
- [∨] 버튼
- 디폴트 : 비활성화
- 활성화 조건 : 아래 2가지 조건 만족 시, 활성화
- ㄴ 조건 1) 3-1 버튼 선택 시
- ㄴ 조건 2) 최하위 항목 外, 선택 시
- 선택 시 → 해당 항목 한 단계 아래(Index - 1) 이동
- 3-3 [Add] 버튼
- 디폴트 : 활성화
- 선택 시 → 최하위 항목 생성 & Process 1 항목 노출
- Process 설정 시, 값 출력 정의
- ㄴ 검체 적용 Process인 경우 → Process에 따른 검체별 디폴트 Setting 값 출력
- ㄴ 검체 미적용 Process인 경우 → Value 최소값 출력
- 3-4 [Delete] 버튼
- 디폴트 : 비활성화
- 활성화 조건 : 3-1 버튼 선택 시, 활성화
- 선택 시 → Confirm_009 노출
- 3-5 [DefaultㅣEnhanced] 버튼
- 최초 진입 시, 디폴트 값 : Default
- 노출 조건 : [TI-STN-03-01-02] 화면에서 선택한 검체가 SurePath인 경우 노출
- Enhanced 선택 시 → Alert_050 팝업 노출
- 수정 O & Save 선택 X인 상태에서 다른 값 선택 시, Confirm_033 팝업 노출

#### 4. 기능 버튼

- [Cancel] 버튼
- Case 1) 수정 내용 X
- 선택 시 → 해당 팝업 닫힘 (팝업 닫기 버튼과 기능 동일)
- Case 2) 수정 내용 O
- 선택 시 → Confirm_012 노출
- [Save] 버튼
- 디폴트 : 비활성화
- 활성화 조건 : 수정 사항 발생 시, 활성화
- 선택 시 → Confirm_010 노출

#### 5. Reset  버튼

- 선택 시 → Confirm_034 팝업 노출
