#### 1. 검체 항목 정보

- 노출 : [TI-STN-03-01-02] 화면에서 선택한 검체 항목 정보 노출

#### 2. Process guide

#### 3. Protocol setting

- 디폴트 : 상위 프로토콜에 따른 하위 검체 항목 상세 값 노출
- 목록 Min/Max 값 정의: 최소 : 1개, 최대 : N개 (수정 필요). 관련 항목 정의 Case 참고
- 3-1 라디오 버튼: 디폴트 : 미선택. 선택 시 → 해당 버튼 활성화
- 3-2 순서 변경 버튼: [∧] 버튼 - 디폴트 : 비활성화, 활성화 조건 : 3-1 버튼 선택 시 & 최상위(No.1) 항목 外 선택 시, 선택 시 → 해당 항목 한 단계 위(Index + 1) 이동. [∨] 버튼 - 디폴트 : 비활성화, 활성화 조건 : 3-1 버튼 선택 시 & 최하위 항목 外 선택 시, 선택 시 → 해당 항목 한 단계 아래(Index - 1) 이동
- 3-3 [Add] 버튼: 디폴트 : 활성화. 선택 시 → 최하위 항목 생성 & Process 1 항목 노출
- 3-4 [Delete] 버튼: 디폴트 : 비활성화. 활성화 조건 : 3-1 버튼 선택 시, 활성화. 선택 시 → Confirm_009 노출

#### 4. 기능 버튼

- [Cancel] 버튼: Case 1) 수정 내용 X → 해당 팝업 닫힘. Case 2) 수정 내용 O → Confirm_012 노출
- [Save] 버튼: 디폴트 : 비활성화. 활성화 조건 : 수정 사항 발생 시, 활성화. 선택 시 → Confirm_010 노출
