### 디스크립션 (원문)

#### 1. Items 개수

- 정의 : 전처리 프로토콜 모든 항목 개수 총합 출력

#### 2. [Delete] 버튼

- 디폴트 : 비활성화
- 활성화 조건 : 목록 1개 이상 선택 시, 활성화
- 선택 시 → Confirm_009 노출

#### 3. 목록

- 컬럼 정의 : [TI-STN-03-01] 화면과 동일
- 3-1 Protocol Name 필드: 공백 포함 최대 50자 입력 가능. 특수문자(\, /, :, *, ?, ", <, >, |) 입력 불가 (우측 Case 참고)
- 3-2 [Apply] 버튼: 선택 시 → 해당 항목 Applied 플래그 노출. 기존 Applied 항목 [Apply] 버튼 노출 (우측 Case 참고)

#### 4. 기능 버튼

- [Cancel] 버튼: Case 1) 수정 내용 X → 선택 시 해당 팝업 닫힘 (팝업 닫기 버튼과 기능 동일). Case 2) 수정 내용 O → 선택 시 Confirm_012 노출
- [Save] 버튼: 디폴트 : 비활성화. 활성화 조건 : 수정 사항 발생 시, 활성화. 선택 시 → Confirm_010 노출
