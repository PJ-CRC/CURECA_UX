## 기존 화면

### 화면 글자

- 상위 Protocol: Protocol Name | Modified by | Modified Date/Time (Test Protocol AA | Admin 01 | 2026-03-24 10:24:56)

- 목록 헤더: Sample Type | Protocol Type | Modified by | Modified Date/Time
- 목록 예: Raw_stool [SG protocol] | Admin01 | -, Cary-blair | - | Admin02 | 2026-03-24 10:24:56, eNAT_stool, Fecal_swab, Surepath, Thinprep, Urine …

### 디스크립션 (원문)

#### 1. 상위 프로토콜 정보

- 노출 : [TI-STN-03-01] 화면에서 선택한 프로토콜 row 정보 노출
- 출력 : 프로토콜명, 편집자 ID, 편집 일자/시간

#### 2. Sample Type

- 노출 대상 : 아래 10개 type 검체 항목 노출: Raw_stool, Cary-blair, eNAT_stool, Fecal_swab, Surepath, Thinprep, Urine, Semen, Saliva, Sputum

#### 3. Protocol Type

- 정의 : Seegene에서 제공하는 프로토콜 하위 값과 동일 여부 체크
- Case 1) Seegene 프로토콜 하위 값과 동일한 경우 → 출력 : 체크 표기
- Case 2) Seegene 프로토콜 하위 값과 다른 경우 → 출력 : 하이픈(-) 표기

#### 4. Modified Date/Time

- 정의 : 상위 프로토콜 최초 copy 시, 모든 항목 하이픈(-) 표기. 단, SG protocol의 하위 프로토콜은 모두 하이픈(-) 처리
- 수정 시 → 수정 일자/시간 출력. 출력 : yyyy-mm-dd hh-mm-ss

#### 5. 상세 화면 이동 버튼

- 선택 시 → [TI-STN-03-01-02-01] 화면으로 이동
