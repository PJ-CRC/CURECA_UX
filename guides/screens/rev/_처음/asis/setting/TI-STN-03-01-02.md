### 디스크립션 (원문)

#### 1. 상위 프로토콜 정보

- 노출 : [TI-STN-03-01] 화면에서 선택한 프로토콜 row 정보 노출
- 출력 : 프로토콜명, 편집자 ID, 편집 일자/시간

#### 2. Sample Type

- 노출 대상 : 아래 10개 type 검체 항목 노출
- Raw_stool
- Cary-blair
- eNAT_stool
- Fecal_swab
- Surepath
- Thinprep
- Urine
- Semen
- Saliva
- Sputum
- (2-1) Enhanced 라벨
- 노출 조건 :
- SurePath의 [TI-STN-03-01-02-01] 화면에서 ‘Enhanced’ 값 설정 시, 노출
- Default로 설정 시, 미노출

#### 3. Protocol Type

- 정의 : Seegene에서 제공하는 프로토콜 하위 값과 동일 여부 체크
- Standard : Seegene 프로토콜 하위 값과 동일한 경우
- Custom :  Seegene 프로토콜 하위 값과 다른 경우

#### 4. Modified Date/Time

- 정의 : 상위 프로토콜 최초 copy 시, 모든 항목 하이픈(-) 표기
- 단, SG protocol의 하위 프로토콜은 모두 하이픈(-) 처리
- 수정 시 → 수정 일자/시간 출력
- 출력 : yyyy-mm-dd hh-mm-ss

#### 5. 상세 화면 이동 버튼

- 선택 시 → [TI-STN-03-01-02-01] 화면으로 이동
