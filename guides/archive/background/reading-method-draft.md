## 1. 지금 프로그램이 읽는 방식 (프로그램 CLAUDE.md 요청 처리 2번)

| 카테고리 | 읽는 범위 |
| --- | --- |
| 작업규칙 (`rules`) | 헌법과 규칙 모두 |
| 정책서 (`policy`) | `README.md` + 머리말 `cids`에 요청 CID가 있는 정책 + 그 정책의 `data` 파일 |
| 기준데이터 (`glossary`) | `glossary.md` + 요청에 걸린 표 |
| UX가이드 (`guide`) | 적용한 가이드 |
| 화면 정의서 (`screens`) | 요청 CID 파일 + 짝 CID 파일 |

- 어긋나면: 화면 내용은 화면 정의서 → 정책서 → 기준데이터 순. 우리 규칙(claude-work 4절)은 정책 · 용어집 → Common UX → 기존 화면 순이라 반대임 (정할 것 1)
- 프로그램은 문서 `meta.json`의 `files` 목록에 있는 파일만 읽음. 새 파일(`policy/modules/`, POL-COM-007 등)은 대표 저장소에 올릴 때 목록에 더해야 함

## 2. 정책을 놓치는 원인

1. 정책을 `cids` 한 길로만 찾음 (`cids`에 빠진 CID, POL-COM · POL-EQP, 정책이 가리키는 정책을 놓침)
2. 정책 파일에서 규칙 절만 읽음 (정의 · 예외 · 이유 · 질문을 놓침)
3. 진행 중 결정(PV · CA · PD, 반영 대기 목록, Module 문서)을 읽는 범위에 넣지 않음
4. 프로그램이 새 파일을 모름 (위 `meta.json`)
