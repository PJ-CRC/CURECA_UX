# DS-0014 Inventory Reagent의 Spare Cap 위치와 부족 표기

## 1. 정할 것
고객(씨젠)이 Inventory Reagent의 Spare Cap 표기를 바꾸어 달라고 요청함.
- Pretreatment Reagents 안의 Tub에 Spare Cap 항목을 더하고, 각 Spare Cap을 해당 Tub 바로 아래에 묶어 보여 줌 (예: LB Tub (Prep) → LB Tub (Prep)_Spare Cap)
- Spare Cap이 비어 있어도, Cap을 꼭 채워야 Run을 마칠 수 있을 때만 부족으로 보여 줌
- 기존 Universal Cartridge Kit의 Spare Cap에도 같은 위치 · 표기 방식을 적용함

## 2. 논의 전 상태
- 화면: TI-IVT-04-T(Ver 2.1.18 기준 `screens/asis/inventory/`)는 Pretreatment Reagents에 Spare Cap 항목이 없고, STARMag Universal Cartridge Kit 아래에 Buffer Cartridge Cap(15 ea, 3 sets)이 따로 있음
- 표기(회의록 m20261126-764894): Spare Cap이 부족하면 모두 보여 줌. 예: 카트리지를 입고하는 5칸 중 2개 카트리지의 Cap이 비어 있으면 Required Qty에 2를 보여 줌
- 정책: POL-INV-003 규칙 5(Remaining Qty와 Required Qty가 모두 0이면 숨김), POL-INV-002 규칙 7(여분의 Cap이 없는 Reagent도 Remaining Qty에 넣음), POL-LOD-004 규칙 13(Tub 5개가 한 세트, Cap도 5개 단위)
