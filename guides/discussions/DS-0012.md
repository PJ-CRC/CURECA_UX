# DS-0012 Assay Pack Setting 화면을 걸린 정책의 cids에 더하고, Import file 팝업(TI-STN-08-01)을 IA에 넣을지

## 1. 정할 것

Assay Pack Setting(케이스 3 다시 그리기, 작업 기록 20261124-최고관리자-setting-2) 2단계에서 화면에 걸리는 정책인데 정책 머리말 `cids`에 그 화면이 빠진 곳을 찾았다(`flow/2-evidence.md` "읽는 법"). 정책 규칙은 바꾸지 않고 `cids`만 더할지, 그리고 `cids`에 더하려는 Import file 팝업 TI-STN-08-01이 IA에 없으니 IA에 넣을지(TI-STN-08 반영 대기 R02 `대기 (확인 필요)`).

## 2. 논의 전 상태

- POL-TST-008 (Assay Pack 관리) `cids`: TI-STN-08, TI-STN-08-P, LI-STN-08, LI-STN-08-P. 규칙 2 · 3 · 4(Import: JSON 여러 개, Alert_041 · Alert_040 · Confirm_028 · Alert_039)는 Import file 팝업 TI-STN-08-01에서 일어남. 알럿 카탈로그 Alert_039 · 040 · 041 · Confirm_028의 사용 화면에는 TI-STN-08-01이 있음
- TI-STN-08-01은 `ia/ia-screens.csv`에 없음 (Setting > Assay Pack Setting 아래는 Details TI/LI-STN-08-P만). 화면 MD `screens/asis/setting/TI-STN-08.md` 반영 대기 R02 "IA에 추가할지 확인"
- POL-TST-010 (검사 항목과 조합 검사) `cids`: TI-STN-08-P는 있으나 짝 화면 LI-STN-08-P는 없음. LI-STN-08-P도 같은 시약 정보(검사군 · 검체 타입 등 Assay Pack에서 받은 값)를 보여 줌 (화면 MD: "화면 글자와 디스크립션 원문은 TI-STN-08-P와 같음")
