# DS-0012 Alert 카탈로그 Confirm_029 · Confirm_030 발생 조건을 POL-TST-008 규칙 6에 맞춤

## 1. 정할 것
Alert 카탈로그(`alert/alert-catalog.csv`)의 Confirm_029 · Confirm_030 발생 조건이 "Assay Pack Setting 목록에서 Active 토글을 켠 / 끈 경우"로 적혀 있습니다. 정책(POL-TST-008 규칙 6)과 기존 화면(TI-STN-08 #4-1 "토글 없음", TI-STN-08-P #3 · #4)은 File details에서 [Active] · [Inactive]로 바꾼 뒤 [Save]를 누를 때 이 Confirm을 띄웁니다. 카탈로그의 발생 조건 · 버튼 동작을 정책에 맞춰 고칠지 정해 주세요.

## 2. 논의 전 상태
- 정책: POL-TST-008 규칙 6 "Master는 항상 최신 버전이 Active이며 바꿀 수 없음. Pretreatment, Extraction, PCR은 File details에서 Active·Inactive를 바꾸고 [Save]로 저장함 (Confirm_029, Confirm_030)."
- 카탈로그: Confirm_029 발생 조건 "Assay Pack Setting 목록에서 비활성 버전의 Active 토글을 켠 경우 ([TI-STN-08 / Popup 정의] 5)", 버튼 동작 "… · Master는 Alert_045". Confirm_030 발생 조건 "Assay Pack Setting 목록에서 활성 버전의 Active 토글을 끈 경우 ([TI-STN-08 / Popup 정의] 6)". 사용 화면 둘 다 TI-STN-08-P
- 기존 화면 (기존 작업방 2.1 2차): TI-STN-08 Ver 0.3.0 #4-1 "토글 없음 … 변경은 상세 [TI-STN-08-P]에서 [Active] · [Inactive]로 바꾼 뒤 [Save]", TI-STN-08-P Ver 0.4.0 #3 "Master : [Active] · [Inactive] 버튼 비활성(변경 불가)", #4 "[Save] → Active로 바꿨으면 Confirm_029, Inactive로 바꿨으면 Confirm_030"
- Alert_045(Master 토글을 고른 경우)는 카탈로그 사용 화면이 "없음"
