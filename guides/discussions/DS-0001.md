# DS-0001 Service Mode를 L-IOS Client Mode로 바꾸고 기능 표를 새 표로 고침

## 1. 정할 것

L-IOS 설치 모드의 공식 이름과 모드별 메뉴 · 기능 표를 무엇으로 할지.

- 이름: 용어집 표준어 "Service Mode", 값 Main Mode · Console Mode · TSS Mode (2026-10-30 결정, `archive/glossary/review-v0.md` Q2). 문서 `policy/service-mode.md` · `policy/service-mode-matrix.csv`, 화면 MD 머리말 키도 같은 이름

## 5. 결정

| 날짜 | 결정 문장 | 정한 사람 |
| --- | --- | --- |
| 2026-11-12 | 공식 문서명은 "L-IOS Client 시스템별 기능 분류", 영어 용어는 "L-IOS Client Mode"로 통일함(Service Mode를 대신함). 모드 값은 Main Mode · Console Mode · MS Mode(이전 TSS Mode). 기능 표는 2절 새 표대로 ① ~ ⑥을 반영하고, Assay Pack Setting 행(Main Mode만 O, 2026-10-30 결정)은 남기며 메뉴 이름은 용어집 표준어 Setting을 씀. 파일 이름은 `policy/client-mode.md` · `policy/client-mode-matrix.csv`, 화면 MD 머리말 키는 `client_mode`로 바꿈. 화면 MD는 이번에 고치지 않고 모두 반영 대기로 남김 | 서보경 |
| 2026-11-12 | 화면 MD도 반영 대기로 두지 않고 이번에 함께 고쳐, 이전 머리말 키와 이전 이름을 문서에서 모두 없앰 | 서보경 |
