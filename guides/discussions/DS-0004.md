# DS-0004 Door 자동 잠금을 없애고 Door Control의 [Lock] 버튼으로 잠그게 할지 (화면 v2.1.17과 POL-EQP-008이 다름)

## 1. 정할 것

화면(기존 작업방 2.1 2차, 버전 메모 v2.1.17 · 2026-11-13 이상헌)은 Door 자동 잠금을 없애고 [Lock] 버튼으로 잠그게 바뀌었는데, 정책서(POL-EQP-008 규칙 3, POL-EQP-004 규칙 7, `policy/equipment-states.md` 5절)는 "다시 잠그는 기능 없음, 닫으면 5초 뒤 자동 잠금"입니다. 어느 쪽이 맞는지, 화면이 맞으면 정책서를 화면대로 바꿀지 정합니다.

## 2. 논의 전 상태

- POL-EQP-008 요약 · 규칙 3: "사용자가 화면에서 Door를 다시 잠그는 기능은 없음. Door를 닫으면 5초 뒤 자동으로 Locked가 됨." (근거: 정책서_2026.08.28 "Door 개폐 및 잠금 전환 규칙", 2026-11-02 사용자 확인)
- POL-EQP-004 규칙 7: "Door가 닫히고 5초 뒤 자동으로 잠기면 Paused였던 Module은 Paused 전 상태로 돌아감."
- `policy/equipment-states.md` 5절 규칙 끝 줄: "Door가 닫히고 5초 뒤 자동으로 잠기고, Paused였던 Module은 다시 가동합니다."
- 화면 LI-INS-01-P (패널 Ver 2.1.13, 버전 메모 v2.1.17): 0 "문을 닫아도 자동으로 잠기지 않음. [Lock] 버튼을 눌러야 Door가 잠김 (Door 단위)", 2-5 [Lock] 버튼(Unlocked일 때 표시, 늘 활성, Open이면 Confirm_031 "Please close the door." · Unlocked 유지), 2-1 [Lock]으로 Locked가 되면 Module 상태 갱신(기존 자동 잠금 뒤 재가동 흐름을 [Lock] 기준으로), 2-6 안내 문구를 [Lock] 안내로
- 화면 LI-INS-01-T 5 · 6 (v2.1.17): Door Control에서 Unlock · Lock 가능. LI-INS-02-T 3 · 3-1 (v2.1.17): Unlocked면 [Lock] 버튼, Open이면 Confirm_031
- 옛 임시 정책 PV-0001 (승인 대기, `old-provisional/`): Run 중 잠금 해제 뒤 Door를 한 번도 열지 않으면 Paused 유지. [Lock]이 생기면 이 경우 사용자가 [Lock]으로 다시 잠글 수 있게 됨
