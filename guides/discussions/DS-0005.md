# DS-0005 씨젠 상태 정보 261119 반영

## 1. 정할 것

씨젠 "CURECA 시스템 구성 요소 및 상태 정보" 261119(2026-11-19 받음)를 저장소 기준 자료에 어떻게 반영할지.

## 2. 논의 전 상태

- 기준 자료는 261021(캡처) 기준이었음. 261021과 비교한 변동 목록은 `reference/updates/2026-11-19_상태 정보.md`
- 새로 바뀐 것: Sample Pre-treatment의 폐기함 Unit 4개(Tip · Film Waste Bin), 장비 통합 상태 전환 조건(21개 → 24개), 장비 모듈 상태 처리 조건 시트(새로 생김), 폐기함 상태의 뜻(만재 센서 기준), 모든 시트에서 "UI 표기 (한글)" 칸이 빠짐
- 코드명: 씨젠은 UI 표기만 DS-0004 이름으로 바꾸고 코드명은 그대로 둠. 저장소 용어집은 DS-0004 때 코드명까지 바꿨음
