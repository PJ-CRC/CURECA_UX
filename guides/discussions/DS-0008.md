# DS-0008 "팝업 · 알럿 · 컨펌 · 토스트" 대신 Popup · Alert · Confirm · Toast

## 1. 정할 것

용어집(`glossary/terms.csv`)은 "팝업" · "알럿"을 쓰지 않는 표현(표준어 Popup · Alert)으로 두고 Popup과 Alert · Confirm을 구분하라고 정했는데, 디스크립션 쓰는 법(`reference-rules/description.md` 2절 "참고")의 예시는 `[Delete] 버튼 클릭 시 팝업 노출 : Confirm_015`처럼 "팝업"을 쓰고 Confirm도 "팝업"이라고 부름. 흐름 문서 · 정책서 · 카탈로그도 "팝업 · 알럿 · 컨펌"을 섞어 씀. 어느 쪽을 따를지(Test Order 케이스 3 테스트, 2026-11-20).

## 2. 논의 전 상태

- 용어집: Popup(쓰지 않는 표현 팝업, 구분해야 하는 말 Alert · Confirm), Alert(쓰지 않는 표현 알럿), Confirm(쓰지 않는 표현 없음)
- `reference-rules/description.md` 2절: "팝업 노출 : Confirm_015", "팝업 노출 : TI-STN-05-01-P"
- 기존 작업방 원문(`screens/asis/`): 187개 가운데 135개에 "팝업"이 503줄. "팝업 노출 :" 뒤에 Confirm · Scan 화면 · COMM 번호 · Alert · CID가 옴
- 흐름 문서 · 정책서 · 카탈로그(`alert/`) · 언어셋 비고에도 "팝업 · 알럿 · 얼럿 · 컨펌"이 섞여 있음
