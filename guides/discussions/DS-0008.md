# DS-0008 Samples 메뉴 화면을 걸린 정책의 cids에 더함

## 1. 정할 것

Samples 메뉴(케이스 3 다시 그리기, 작업 기록 20261120-최고관리자-samples) 2단계에서 화면에 걸리는 정책인데 정책 머리말 `cids`에 그 화면이 빠진 곳을 찾았다(`flow/2-evidence.md` "읽는 법"). 정책 규칙은 바꾸지 않고 `cids`만 더할지.

## 2. 논의 전 상태

- POL-SMP-001 (Sample 상태와 전환) `cids`: TI/LI-SPT-01은 있으나 Details(TI/LI-SPT-01-01)는 없음. Details 1 타이틀 영역 · 3 General에 Sample Status를 보여 줌 (기존 작업방 Ver 2.1.11)
- POL-TST-001 (Policy Setting 공통) 규칙 8: Allow Protocol Changes Before Test가 On이면 Run 준비에 Check Test Protocol 단계를 둠, Off면 Apply한 Protocol을 씀. Protocol Info(TI/LI-SPT-01-02 · 03) 2 "Run Preparation 단계에서 선택한 프로토콜 / 선택하지 않을 경우 Applied된 프로토콜"이 이 규칙을 따름. `cids`에 없음
- POL-TST-006 (Protocol Setting) 규칙 6: 종류마다 Apply한 Protocol 하나가 Applied. Protocol Info 2 · 3이 이 규칙과 Protocol Setting 화면을 가리킴. `cids`에 없음

## 3. 제안

| 제안 | 내용 | 고르면 바뀌는 정책 문장 | 영향 화면 |
| --- | --- | --- | --- |
| A (추천) | 세 정책의 `cids`에 화면을 더함. 규칙 문장은 그대로 | POL-SMP-001 `cids` + TI-SPT-01-01, LI-SPT-01-01 / POL-TST-001 `cids` + TI · LI-SPT-01-02, 01-03 / POL-TST-006 `cids` + TI · LI-SPT-01-02, 01-03 | 없음 (화면은 이 작업에서 정책 ID를 디스크립션 끝에 이음) |
| B | 더하지 않음 | 없음 | 없음 |
