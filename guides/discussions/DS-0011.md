# DS-0011 Door 자동 잠금을 없애고 [Lock] 버튼으로 잠글지 (Instrument 화면 v2.1.17과 POL-EQP-008이 다름)

## 1. 정할 것
Door를 닫으면 5초 뒤 자동으로 잠기는 정책(POL-EQP-008 규칙 3)을 기존 화면 v2.1.17처럼 "자동 잠금 없음, [Lock] 버튼을 눌러야 잠김"으로 바꿀지 정합니다. 바꾸면 문이 열린 채 [Lock]을 누를 때의 안내(Confirm_031)를 알럿 카탈로그에 올립니다.

## 2. 논의 전 상태
- 정책: POL-EQP-008 규칙 3 "사용자가 화면에서 Door를 다시 잠그는 기능은 없음. Door를 닫으면 5초 뒤 자동으로 Locked가 됨", POL-EQP-004 규칙 7 "Door가 닫히고 5초 뒤 자동으로 잠기면 Paused였던 Module은 Paused 전 상태로 돌아감", `policy/equipment-states.md` 5절 규칙 (2026-11-02, 정책서_2026.08.28 · 사용자 확인)
- 기존 화면 (기존 작업방 Instrument 페이지, Ver 2.1.17 · 2026-11-13 · 이상헌, Figma 버전 메모): Door Control Popup (LI-INS-01-P) 0 · 2-1 · 2-5 · 2-6 — 자동 잠금 폐지, Unlocked Door의 버튼이 [Lock](늘 활성), [Lock]을 눌러야 잠기고 그때 Module 상태가 갱신됨, Door가 Open일 때 [Lock] → Confirm_031 "Please close the door." / "The door is open. Close the door, then press Lock again." / [OK]. Overview Tab (LI-INS-01-T) 6, All Tab (LI-INS-02-T) 3 · 3-1에도 [Lock] 정의가 더해짐
- 알럿 카탈로그(`alert/alert-catalog.csv`)에 Confirm_031이 없음
- 화면 정의서의 반영 대기 LI-INS-01-P R02 · R06은 정책(자동 잠금) 기준으로 적혀 있어 기존 화면과 반대 방향임
- 참고: POL-LOD-001 규칙 10 (단디메카는 유리문을 닫으면 Door가 자동으로 잠기고 Trolley가 도킹됨)
