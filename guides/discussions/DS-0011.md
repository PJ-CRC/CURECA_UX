# DS-0011 Empty Waste Bin은 Console Mode에서만 제공함

## 1. 정할 것

Material Setup > Empty Waste Bin(비움 처리)을 Main Mode에서도 제공할지.

## 2. 논의 전 상태

- 2026-11-03: 사용자 설명은 Main Mode · Console Mode 모두, 그때의 Service Mode 표는 Console Mode만이라 고객과 다시 정하기로 함(CA-0007). POL-INV-005 규칙 5는 "지금은 Console Mode에서만"으로 두고 참고에 "Main Mode에서도 제공할지는 고객과 다시 정함 (CA-0007)"

## 3. 제안

| 제안 | 내용 | 고르면 바뀌는 정책 문장 | 영향 화면 |
| --- | --- | --- | --- |
| 가 | L-IOS Client Mode 기능 표대로 Console Mode에서만 | POL-INV-005 규칙 5의 "지금은"을 빼고 참고 줄을 지움 | 없음 (화면은 이미 Console Mode만) |
