# DS-0002 L-IOS Client Mode별 용도 설명을 새 기능 표에 맞게 다시 쓰기

## 1. 정할 것

Console Mode와 MS Mode는 각각 어떤 자리에서 무엇을 하려고 쓰는 모드인지. 2026-11-12 새 기능 표에서 Consumable·Reagent 준비가 Console Mode로 옮겨져, `policy/client-mode.md` 0절의 용도 설명이 기능 표와 맞지 않습니다.

## 2. 논의 전 상태

`policy/client-mode.md` 0절 (v0.1, 2026-10-30, 고객사 요청으로 모드를 나눈 이유):

- Console Mode: 끌고 다니는 이동형 컴퓨터(바코드 스캐너 있음). 장비에 무언가를 넣거나 비우는 메뉴만 보임
- MS Mode(이전 TSS Mode): 장비와 떨어진 준비 공간의 컴퓨터. 장비 가동 전에 넣을 Consumable과 Reagent를 준비(Trolley 구성, PCR Reagent 구성 등). Reagent는 오염에 민감해 분리된 공간에서 작업할 수 있음

2026-11-12 기능 표(DS-0001): Group Lots, Load Consumables and Reagents into Trolley, Load PK/IC Tubes, Load PCR Reagents, Load MM Tubes는 Console Mode만 O. MS Mode의 Material Setup은 Load Samples into Trolley만 O.
