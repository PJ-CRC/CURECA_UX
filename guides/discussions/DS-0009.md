# DS-0009 Error인 Module은 Door를 열어도 Error를 유지하고, 오류 복구가 끝날 때까지 Error로 둠

## 1. 정할 것

- 장비 모듈 상태가 Error일 때 Door 잠금을 풀거나 열면 Error가 유지되는지, Paused가 되는지 (예전 CA-0010)
- Error를 처리하고 Door를 닫았는데 검사 가능 상태 확인 결과가 정상이 아니면 어떻게 되는지 (예전 CA-0002)

## 2. 논의 전 상태

- POL-EQP-004 규칙 1: "Door 잠금이 해제되면 그 Module의 장비 모듈 상태는 Paused가 됨. 장비 통합 상태가 Ready, Not Initialized, Error일 때도 같음."
- 2026-09-22 고객 회의(MT-20260922-01): "Error면 Door를 열어도 Error 유지". 규칙 1과 달라 고객 논의 대상(CA-0010, 2026-11-06)으로 올림
- Error 복구는 "Door를 닫으면 검사 가능 상태를 자동으로 확인하고 정상이면 Ready"만 있고, 정상이 아닐 때가 없었음(CA-0002, 2026-11-02, `policy/policy-backlog.md` 추가할 것 12)
