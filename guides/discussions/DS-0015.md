# DS-0015 PCR Reagent Lot 구성 범위 (IC Tube만 → 박스 안 모든 Tube)

## 1. 정할 것
고객(씨젠)이 PCR Reagent의 Lot 구성(Group Lots > Group PCR Reagent Kit) 범위를 바꾸어 달라고 요청함.
- 지금은 PCR 시약일 때 IC만 Lot grouping을 함
- 앞으로는 박스 안에 들어 있는 모든 Tube를 Lot grouping함

## 2. 논의 전 상태
- 정책: POL-MAT-009 정의 표(PCR Reagent Kit = PCR box + IC Tube), 규칙 2(IC와 PK Tube는 Barcode 체계가 달라 Lot을 구성함), 규칙 3(PCR box와 IC Tube를 모두 스캔해야 [Done] 활성), 규칙 5(IC Tube가 없는 PCR box는 MS_Alert_006, Lot 없이 Load PCR Reagents에서 바로 적재). POL-MAT-008 규칙 4(IC가 없는 PCR box는 Lot 없이 적재), POL-INV-007 규칙 4(IC는 Lot 구성을 함)
- 화면: LI-TSS-LTG-02-01 → 02-02 (Group PCR Reagent Kit)
