# DS-0003 장비 통합 상태의 영문 · 화면 라벨을 CURECA Status로 정하고, 상태값 분류 이름을 Hardware Status로 바꿈

## 1. 정할 것

1. 장비 통합 상태(CURECA 전체의 상태)를 화면 · 알럿 영어 문구에서 무엇으로 부를지.
2. 1에서 CURECA Status로 정하면, 같은 말을 쓰던 상태값 표의 분류 이름을 무엇으로 바꿀지.

## 2. 논의 전 상태

- 용어집 `glossary/terms.csv` 장비 통합 상태 줄의 영문 · 화면 라벨: `(화면 라벨 확인 필요)` (2026-10-30 결정 때 비워 둠)
- LI-STN-02 System Setting의 저장 불가 알럿(Alert_049) 영어 문구를 쓰면서 필요해짐. 그때까지 임시로 "instrument"로 적었음
- `glossary/status-values.csv` · `glossary/glossary.md` · POL-EQP-001 · `policy/equipment-states.md`는 "CURECA Status"를 장비 자체의 상태 전체(장비 통합 상태 · 장비 모듈 상태 · 검사 장치 상태 · Unit Type별 상태)를 묶는 분류 이름으로 씀. 짝 분류는 System Status(소프트웨어가 관리하는 상태)
- 다른 후보였던 Instrument Status는 용어집에 이미 Dashboard 등의 영역 제목(여러 상태값을 묶어 보여 주는 영역, 하나의 상태값 이름이 아님)으로 있어 쓰지 않음
