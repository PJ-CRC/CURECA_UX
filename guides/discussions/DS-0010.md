# DS-0010 Run 중 Door 잠금을 해제한 뒤 Door를 열지 않아도 Paused를 유지함

## 1. 정할 것

장비 통합 상태가 Running · Partial Running · Paused일 때 Door 잠금을 해제해 Module이 Paused가 된 뒤, 사용자가 Door를 한 번도 열지 않으면 그 Module은 어떻게 되는지.

## 2. 논의 전 상태

- POL-EQP-008 참고: "Run 중 잠금을 해제한 뒤 Door를 한 번도 열지 않은 경우의 동작은 아직 정의되지 않음. 임시 정책 PV-0001을 따름."
- 임시 정책 PV-0001(2026-11-02 등록, 승인 대기): 정의될 때까지 Paused 유지로 진행. 8월 정책서의 "문을 한 번도 열지 않으면 Unlocked를 유지하다가 Run 시작 시 자동 잠금"은 Run 중 잠금 해제가 불가하던 때의 규칙이라 맞지 않음

## 3. 제안
