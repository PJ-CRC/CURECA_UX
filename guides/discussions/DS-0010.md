# DS-0010 Protocol Info Extraction Protocol의 STARlet 화면

## 1. 정할 것

Protocol Info - Extraction Protocol을 M9600 기준으로만 그렸음. Setting에 STARlet용 Extraction Protocol 화면(TI-STN-03-02-02-V)이 있어 장비별 화면이 필요한지 (질문 대기 Q12).

## 2. 논의 전 상태

- 기존 작업방 화면(2.1 2차)과 정책서 · 알럿 · 토스트 카탈로그에 정해진 것이 없음. 작업 기록 20261123-최고관리자-samples-2 3단계에서 질문 대기로 그림.

## 3. 제안

| B | M9600 기준 하나로 둠 |
