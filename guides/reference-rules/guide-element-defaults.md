# 가이드 요소 기본값

> 상태: 확정 v1.0 (2026-11-10, 사용자 결정). Common UX 담당자가 보고 고칠 곳이 있으면 고칩니다. Common UX - PC 기준이고, 모바일 가이드를 쓰는 파일은 그 가이드로 따로 만듭니다. 가이드 규칙은 가이드 원본에서 읽습니다.

기존 화면에는 없지만 Common UX가 정해 둔 요소를 넣을지 미리 정해 둔 표입니다. 이 표가 있으면 1단계에서는 표에 없거나 "물음"인 요소만 묻고, 4명이 같은 요소를 같게 넣습니다.

## 기본값의 뜻

| 기본 | 하는 일 |
| --- | --- |
| **넣음** | 묻지 않고 넣음. 기존 화면에 없던 요소가 생긴 것이므로 3단계에서 `※ 변경 확인`을 두어 담당자가 확인하게 함 |
| **물음** | 3단계에서 `※ 질문 대기`로 둠 (화면 동작이나 흐름이 기존과 달라지는 것) |
| **원본에 있을 때만** | 기존 화면에 있을 때만 가이드 모양으로 맞추고, 없으면 넣지 않음 |

- 기존 화면과 가이드가 **다르게** 정한 것(있는 요소의 모양 · 동작이 다름)은 이 표가 아니라 우리 기준(정책 · 용어집) > 가이드 > 기존 화면 순서로 따르고, 가이드와 우리 기준이 다르면 `common-ux/feedback.md`에 올립니다.
- 넣은 요소의 값(기본값 · 문구 등)은 디스크립션에 적고, 가이드 규칙은 다시 쓰지 않고 가이드 번호로 잇습니다.
