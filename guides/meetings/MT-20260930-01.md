## 내용

```text
[논의사항]
1. 검체 Trolley 교체 가능 여부 알림 → 일정 추후 재논의 예정 (2차 반영 필요)
1-1) Test status
- Running 상태: 검체 스캔 시점
- Complete 상태: DWP 분주 완료 시점

1-2) Inventroy > Overview tab
- Sample storage 항목 생성
ㄴ Sample(Inbound) / Sample(Oubound) 표기
ㄴ Prep과 동일 기조로 수량, 단위 표기 및 Capacity 제거
ㄴ Sample storage와 다른 모듈을 디자인적으로 구분 → 내부 논의 후 전달

- 표기 항목 재구성
ㄴ 수량, 단위 표기
ㄴ 퍼센트, Capacity 제거
ㄴ Sealing film 입고 결과, 잔여량 = 투입량인 경우, 하나만 표기

2. Run 준비 화면 내 소모품/시약 상세 정보 제공 여부
- 추가 완료

3. Material Setup 내 Dx 소모품/시약 필요 수량 정보 제공 기능 추가 검토
- 필요 수량 기재 필요 (투입트롤리 docking 시에만 노출)
- 기기 스케줄링에 따라 PCR rack 작업 진행
- DX 스캔 시, 그에 따른 모듈명 or 인덱스 번호 노출 필요

4. Run 준비 화면에서 Waste Bin 상태 조회 탭 추가 검토 건
- Run/Quick run > Waste bin 상태 스텝 추가 (step 4~5)
ㄴ 개수 > 폐기함 기준으로 표기
- Run preparation > 추가할 항목 없는 case 추가 필요
```
