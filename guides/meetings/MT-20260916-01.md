# MT-20260916-01 화면 UX 리뷰

> 스프레드시트 0.회의록의 기록을 2026-11-04에 원문 그대로 옮겼습니다. 안건 · 결정 · 할 일 · 정책 후보는 정리하지 않았습니다 (`rules/meeting-notes.md` 7절).

## 내용

```text
[Drawer Loading]
- 메뉴명 논의 (트롤리 입고 포함되는 부분)
- 가이드 화면 내 Door Control

[Waste Bin manage]
- UI 작업 시, 버튼 영역에는 버튼 형태 노출, QR 영역에는 QR 이미지 형태 노출 요청

[Reuse guide]
- 확인 방식이 아닌, 단순 View 방식으로 전환 요청
- Reset은 명시적으로 하는 것이 아닌, 리셋이 안된 물품을 다시 재사용 기점으로 리셋여부 팝업 노출 요청
- IC/PK 및 스탠다드 튜브일 경우, 사용 중인 것을 재입고할 때, 제거해야하는 범위 이미지 팝업으로 재노출 요청
- Tub 경우도 트레이 입고 단계에서 리셋여부 묻고, 리셋일 경우 step1부터 시작 안내, 재사용일 경우 뚜껑 추가로 장착하여 사용하도록 알럿 노출 요청

[정책]
- 검체/소모품 스토리지도 Running 중에 일시 정지를 통해 열 수 있음
- 모듈 상태가 Ready일 경우에도 Door를 열면 Paused로 상태로 변경
- Drawer 입고 시 가이드 화면이 띄워진 상태에서 문을 닫을 경우 자동으로 화면이 전환되며 저장 (Sealer 예외)

[기타]
- 대시보드 및 실시간성 데이터 표기 메뉴 데이터 리프레시 주기 : 모두 실시간성 반영
  ㄴ 모든 항목별로 이벤트 보내주기 때문에 이벤트 푸시에 따라 실시간 반영 적용 예정

- Door Control
  ㄴAll door open 버튼의 열 수 있는 문의 숫자 제거
  ㄴDoor 오픈 시, module 상태값은 'Paused' 상태로 변경(정책 추가)
  ㄴ검체 및 소모품 트롤리 입고 모듈도 Running 일때, Door 오픈할 수 있게 정책 수정

- Inventory waste bin status
  ㄴ Full은 만재 센서 기준으로 값이 변경되게 적용
  ㄴ 예상 폐기량이 100% 넘어서도 만재가 울리지 않을 경우, 100% 표기로 유지하며 상태값도 Almost Full로 유지

[소모품/시약]
- 시약 20종 추가
- 기존 STAT 입고 내역 Trolley로 변경 내역 반영
- PCR Setup용 배치도는 추가로 작업해서 전달할 예정
- (v.n.x) 버전 정보는 제외하고 제품명 표기(IC는 기입된 정보 그대로 표기)
- TSS G40,41 내역은 확인 후 다시 수정 후 전달 예정
- TSS 에서 PCR 시약 제거 시 Uesd 처리 (그룹핑된 IC도 함께 Uesd 처리)
```
