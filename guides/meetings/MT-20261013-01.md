## 내용

```text
[Inventory]
- Overview > Sample Storage 영역
ㄴ 데이터 표현은 동일 기조로 유지, UI 요소를 접목시켜 구분만 될 수 있도록 처리 필요 (ex. 기획서 라인처리)

- Consumables Tab
ㄴ 현재 제안한 카드섹션 순서 유지

- Reagents Tab
ㄴ그룹화 순서는 전처리, 추출, PCR 순으로 정렬
ㄴ 그룹 내, 항목은 알파벳 오름차순 정렬
※ 그룹, 비그룹 함께 정렬 시 → (1) 그룹명 알파벳 오름차순 우선 정렬, (2) 비그룹화 항목끼리 알파벳 오름차순 정렬

- Waste Bin/Bottle Tab
ㄴ 모듈 배치 순 정렬

- Cap이 없는 시약도 잔여 수량에 포함하는 방식으로 적용(현 상태 유지)

[Assay pack]
- 상세 화면에서 모든 정보 노출 필요
- 개발사 협의 & 정보 정제 후 재공유 예정
- 검사 Target 선택 가능 여부 > Checked인 경우, 선택 가능하도록 설계 필요 (=Editable)
- 추출 장비별 사용 가능 정보 > 디폴트로 사용 설정된 장비를 의미함 (Unchecked이라도 사용 설정 가능)

[가동리포트]
- Preview 선택 시, PDF viewer로 노출
- 특정 배치에 대한 Event summary 정보 필요
- Run Time, Operate Count, Event > 누적 정보와 현재 배치 정보 노출 필요

[통계]
- 장비 유형별 이벤트 발생 건 수, 이벤트 유형별 발생 건 수가 유의미할 것으로 보임
- 현업 내부적으로 검토 후 의견 전달 예정
```
