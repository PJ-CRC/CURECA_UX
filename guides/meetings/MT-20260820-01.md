# MT-20260820-01 Prep 장비별 특성에 따른 이슈 논의

> 스프레드시트 0.회의록의 기록을 2026-11-04에 원문 그대로 옮겼습니다. 안건 · 결정 · 할 일 · 정책 후보는 정리하지 않았습니다 (`rules/meeting-notes.md` 7절).

## 내용

```text
[장비별 현황]
- 단디메카: STAT 4칸 사용 가능, Sample Storage에 냉장 버퍼 4칸 사용 가능
- 로체시스: STAT 3칸 사용 가능, Sample Strorage에 버퍼 공간 없음

[이슈]
- IC 소켓이 STAT으로 들어갈 경우, 로체의 경우 보관할 버퍼 공간이 없어서 Sample storage 트레이에 보관을 해야함.
- 트레이 내 1칸만 사용할려고 했는데, 연속런의 경우 검체 트롤리를 변경 할 때(연속 런 케이스), 그에 맞는 IC와 PCR을 추가로 입고해줘야 함. 다만 이때 1개의 버퍼공간만 사용한다면 이전 검사와 다른 IC가 들어가는 케이스일 경우 IC 소켓을 추가로 입고할 수 없음.
- 그래서 추가로 공간을 더 확보해야함. (단디 기조에 맞춰 4칸 정도 예상 중)
- 문제점: 검체 트롤리 입고 영역을 버퍼로 사용함에 따라, Run이 끝나고 검체 트롤리를 제거할 시점에 PCR 시약이 스토리지에 남아 있으면 IC 소켓이 제거되면 안됨.
  ㄴ 방안 씨젠 제안: 트롤리 회수할 때 사용자가 직접 꺼내 IC 남은 것들을 다시 하나로 합쳐서(TSS 재작업) 입고해서 사용될 수 있는 정책 설정
  >> 우려: PCR 리셋 기능을 사용할 경우, 해당 PCR의 IC를 함께 제거하기 무리가 있음. IC는 Sample storage 버퍼 공간에서 관리되고 있기 때문에 중간에 꺼내기가 어렵고 런이 끝난 후 검체 트롤리를 제거할 때 육안으로 어떤 IC가 PCR과 페어링되는 지 확인할 수 없음. 또한 Prep은 자동 폐기가 아니라서 IC에 페어링된 PCR이 모두 사용완료되어 폐기된 시점을 파악해서 STAT으로 IC소켓을 리턴시켜서 사용자가 직접 제거하게 해야함. 이런 복잡성으로 인한 사용자의 인지부조화로 인한 에러케이스가 발생될 것으로 예상됨

[기타 논의]
- DX 시스템의 소모품/시약 slot의 경우 가변형으로 대응 가능하도록 적용(재단용과 생산용의 소모품 입고 slot 수가 상이함. 모듈 내에 공간이 부족하여 어쩔 수 없이 표준형은 더 줄인 개수로 적용될 예정)
- 확실한 slot 개수는 아직 미정이라 최종 fix된 후 공유할 예정
  ㄴ브렉스) 장비 slot 관리는 하드웨어 단에서 관리하고 우리는 가변적으로 올라오는 값이 표기되는 방향으로 반영(디스크립션에 관련된 영역에 내역 추가할 예정)
  ㄴ리셋(delete) 팝의 경우, slot 개수가 가변적으로 보이도록 UI 수적 필요. 스크롤 생성도 무방
  ㄴMB Tube는 10칸에서 5칸으로 사용됨에 따라, 물리적으로 남은 5칸의 입구를 막아서 사용할 예정. 이에 따른 MS 화면의 이미지 5칸으로 보이게 수정 요청
  ㄴTip 및 MB Tube 같이 위치값 없이 입고되는 케이스일 경우, 리셋(delete)의 경우 all reset 되는 방식으로 적용
  ㄴSTAT도 3~4칸 사용에 따라 MS화면의 이미지가 3칸정도만 보이게 수정 요청
```
