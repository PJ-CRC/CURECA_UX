# MT-20260821-01 STAT Storage 정책 및 소모품 trolley 정책 변경에 따른 이슈 논의

> 스프레드시트 0.회의록의 기록을 2026-11-04에 원문 그대로 옮겼습니다. 안건 · 결정 · 할 일 · 정책 후보는 정리하지 않았습니다 (`old-rules/meeting-notes.md` 7절).

## 내용

```text
[STAT Storage 정책 변경]
1) PK/IC가 상온 보관이 가능한 것으로 확인되어, Prep Consumable Storage의 Trolley에 장착하여 운영한다.
2) Trolley를 Undoking한 후 잔여 PK/IC는 Material Setup 메뉴를 통해 신규 Socket으로 옮겨 장착한다. (다른 소모품/시약과 동일한 운영 방식)
3) STAT Storage에 투입 가능한 물품을 검체로 제한하며, 슬롯은 논리적 점유 방식으로 운영한다.
4) STAT Storage에 검체를 추가로 투입하여 소모품/시약이 부족한 경우, Prep Consumable Storage의 Trolley 교체를 통해 보충한다. (사용성 측면에서 불편이 발생할 수 있으나, STAT Storage 사용 빈도는 낮을 것으로 예상)

>> STAT 관련하여 전반적으로 검토 후 화면 수정 진행 필요
*예상 범위
ㄴInventory : Location 정보 변경
ㄴTSS: 입고 화면의 툴팁내 STAT 메시지 내용 변경. 소모품 트레이 장착 화면영역 내 소모품 개수 표현 영역 변경(기존 개수 15개에서 6개 추가하여 21개 변경됨)
ㄴIC/PK 구성 메뉴: 현안 유지(씨젠 시나리오: 소모품 트롤리 제거 후 PK/IC 소켓을 회수하여 남은 튜브와 새로 넣어야 하는 튜브들과 다시 구성하여 넣는 식으로 가이드할 예정)

*추가 안전 장칙(알럿)
ㄴSTAT에 Sample 외에 소모품을 넣을 경우, 입고 불가 알럿 추가
ㄴSTAT에 Sample 입고 후 회수 안된 위치에 다른 것을 넣을려고 할 때, 사용중이라는 알럿 추가

[소모품 Trolley 정책 변경 건]
-최초 정책: 모두 사용 후 폐기되는 방향(즉 새제품만 넣는 방향으로 설계)
-실제 구현: 검사 종료 후 트롤리 제거 시, 사용 후 남은 것들은 입고되었던 위치에 회수되는 구조
(사용한 것 폐기 후 남은 것만 회수되는 소모품: Tip, Swab / 폐기되지 않고 사용한 것과 미사용한 것이 함께 회수되는 소모품: Tube, Tub, IC, PK)

이슈
ㄴ다시 리턴된 일부 사용된 소모품인 경우, 다시 구성할 때, 장비가 사용한 시점을 인지하고 연속으로 사용할 수 있는 지 체크 -> 개발사에 이렇게 개발될 수 있게 적용 요청 예정
   ㄴ문제점: 사용자가 사용된 것과 미사용된 것을 구분하여 직접 제거해야 해서 휴먼에러가 발생될 수 있음. 실제로 사용안한 것을 추가로 제거하거나 사용된 것이 사용안한 자리에 섞여서 다시 장비에 들어갈 케이스
   ㄴ 방안: 장비가 재사용하는 소모품의 위치값에 실제로 소모품이 없다면 3번 정도 위치를 옮기면서 시도해보고 그래도 없으면 동일한 소모품으로 사용되고 오류를 발생시킨 소모품은 사용하지 않고 회수시킴. 또한 장비가 사용할 때, 사용했던 tube인지 체크하여 사용하는 로직 추가
   ㄴ문제점: run start 시점으로 자재값을 모두 리셋하기 때문에 해당 값을 들고 있을 수 없음
   ㄴ 방안: 바코드 기반으로 남은 개수를 확인할 수 있고, 어디까지 사용했는 지 유추할 수 있는 방식이 필요함
- 일부 소모품이 부족할 경우, 트롤리 제거하고 다시 구성하여 사용함(트롤리는 런스타트 기점으로 리셋이 되기 때문에 빼는 순간 다시 넣는 소모품을 재작업해야함)
```
