## 기타

```text
- 소모품 트롤리 Tube 리셋 기준 논의
  ㄴ소모품 트롤리는 리셋하지 않는 것으로 정의 완료

- 소모품 트롤리 교체 시 로직
1) 장비 가동 중 트롤리를 언도킹하기 위해서는 모든 물품(검체, 소모품, 시약)이 트롤리로 반환되어야 함.
  -> 트롤리 언도킹 요청 시 전처리 모듈 내부로 이동된 물품에 대하여 진행 중인 작업을 완료한 후 반환 처리함
  -> 해당 반환 처리 작업 시간이 수분에서 수십분 정도 소요될 것으로 예상
  -> 이에 따라 사용자에게 언도킹 수행 대기 안내를 제공(기 적용 사항)해야 하며, 추가로 언도킹 가능 여부 상태 표시 기능 적용 검토 필요(모든 서랍형 저장 장치(실러 저장소 제외) 및 폐기함도 동일하게 적용 검토 필요)
  -> 또한, 현재 트롤리 언도킹에 대한 사용자 트리거로 도어 Unlock 버튼을 활용하고 있으나, 트롤리 언도킹 요청 버튼을 추가하여 도어 Unlock과 분리하는 방안 적용 검토 필요 (예: Prep 저장소 모듈 Door Unlock 버튼 클릭 시 Unlock 범위 선택)

참고
- 검체 투입 트롤리에 적재된 검체 랙은 복수개를 로딩하지 않고, 하나씩 순차적으로 로딩하여 처리함
```
