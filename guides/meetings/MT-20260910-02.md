## 내용

```text
[Instrumnet - Door control]
- Unlock 버튼은 항상 노출하는 방향으로 변경 요청

[소모품 트롤리 reuse 메뉴]
- standard tube 제거해야하는 영역 디자인 변경 요청
- 재사용 영어 단어 일부 변경 요청

[가동 리포트]
- Batch 단위로 자동 생성되는 구조
- 모듈 구조 정보는 현재 시스템에 있는 구조와 동일하게 적용 (Sample preparation ~ PCR)
- SW 버전 정보 중 CFX96, Viewer 정보는 내부적으로 관리하고 있을 것으로 생각됨, 노출하는 방향으로 진행
- 구동 ID는 실제 Run Start를 누를 사용자 ID 정보 노출
- 종료 상태는 선택된 배치의 종료 상태 노출 (Failed / Completed)
- Maintenance 상태는 모듈 중 하나라도 상태 값이 Failed 이라면 전체 상태 값도 Failed로 노출
- Run Summary는 하나의 배치 카드 정보 노출
- 구동 시간 상세 이력
ㄴ 이벤트 유무 정보 > 이벤트 개수 노출
ㄴ 처리 결과, 지연된 시간, 재검 필요 여부 삭제
- 이벤트 이력 정보 삭제
- 누적 구동 이력 : 배치 레벨에 맞는 정보 X, 삭제
- 유지보수 예측 : 현재 노출할 수 있는 정보의 범위를 알 수 없음 / 항목과 Pass 여부만 노출하는 방향으로 우선 진행
```
