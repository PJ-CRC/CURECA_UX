# 언어셋 (다국어)

6개 언어(영어, 한국어, 포르투갈어, 스페인어, 이탈리아어, 프랑스어) 문구를 관리하는 언어셋을 둡니다. 언어셋은 엑셀이며 ID 체계와 고유명사 관리가 있습니다. 사용 방법은 [rules/language-set.md](../rules/language-set.md)를 따릅니다.

| 파일 | 내용 |
| --- | --- |
| `translation-requests.csv` | 번역 요청 목록. 언어셋에 없는 새 영어 문구를 모아 고객사에 번역을 요청 |

> 상태: 언어셋 담당자가 현재 기준 언어셋을 공유하고, 담당 Claude와 협의해 관리 체계를 정합니다.
