# 작업 기록

화면설계 작업 하나마다 파일 하나를 둡니다(0단계에서 만들고 7단계에서 닫음). 틀과 쓰는 법은 [reference-rules/work-log.md](../reference-rules/work-log.md)입니다.

- 파일 이름: `YYYYMMDD-<요청자>-<대상>.md` (예: `20261110-서보경-samples.md`)
- 열린 기록(`status: 진행 중`)은 0단계 겹침 확인에 쓰입니다.
- 끊긴 작업은 "작업 기록 `<이름>` 이어서 해 줘"로 이어 갑니다.
- 끝난 기록(`status: 끝남`)도 지우지 않습니다(헌법 9조).
