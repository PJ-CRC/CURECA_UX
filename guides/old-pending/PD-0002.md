# PD-0002 SMTP Setting의 [Save] 범위

| 항목 | 내용 |
| --- | --- |
| 상태 | 대기 |
| 대상 자료 | POL-SYS-003, TI-STN-06 |
| 제안자 | 서보경 |
| 제안일 | 2026-11-02 |
| 긴급 | 아니오 |

## 제안 내용

SMTP Setting에서 Use SMTP Feature를 Disable로 바꿨을 때 어떻게 저장되는지 정합니다.

- 지금 디스크립션: "Use SMTP Feature 설정 값이 Disable인 경우 [Save] 비활성화". 그래서 Enable에서 Disable로 바꾸고 저장할 방법이 화면에 없음
- (가) Disable로 바꾸는 순간 자동 저장해 SMTP를 끔
- (나) Disable로 바꾼 것도 변경으로 보고 [Save]를 활성화해 저장
- 어느 경우든 [Save]가 다루는 범위(어떤 항목이 바뀌면 활성화되는지)를 디스크립션에 분명히 적음

## 이유와 근거

- TI-STN-06 디스크립션 5 [Save] 버튼
- 2026-11-02 사용자: 화면 설계자와 다시 논의 후 결정
