# 참고 원본 자료

외부에서 받은 원본 자료를 받은 그대로 보관합니다. 우리가 관리하는 정책이 아니라, 정책의 출처입니다.

- 원본은 고치지 않습니다. 새 버전을 받으면 이전 파일을 지우지 않고 새 파일로 추가합니다.
- 받은 날짜와 버전을 이 폴더의 목록에 남깁니다.
- 정책서와 기준 자료는 이 파일을 출처로 인용합니다.

| 폴더 | 내용 |
| --- | --- |
| `customer/` | 고객사가 넘겨주는 상태 정보, 시약 정보 파일 |

> 상태: 파일 형식과 갱신 주기 확인 필요 (`background/worklist.md`).
