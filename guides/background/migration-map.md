# 옮김 대조표 (기존 규칙 → 새 구조)

> 상태: 1차 (2026-11-09). 기존 절차 문서의 절 · 항목마다 새 구조의 어디로 가는지, 빼면 왜 빼는지를 적었습니다. 단계 문서를 채울 때 이 표를 보며 옮기고, 옮긴 줄은 "옮김 확인"에 날짜를 적습니다. 모든 줄에 날짜가 채워지면 기존 문서를 `archive/`로 옮깁니다(`background/cleanup-plan.md` 6절).

**처리**

| 처리 | 뜻 |
| --- | --- |
| 옮김 | 내용 그대로 새 위치로 |
| 고쳐 옮김 | 새 위치로 옮기되 "고칠 점"대로 고침 |
| 뺌 (문서만) | 그 자리는 없애고 내용은 다른 줄에서 옮김 |
| 뺌 (내용) | 버림. 이유를 적음 |
| 요청서로 | 프로그램 화면 · 버튼 명세라 규칙에서 빼고 요청서로 |
| 헌법 개정 | 헌법을 고쳐야 함. 함께 확인하고 정함 |
| 다시 정함 | 그 단계 문서를 쓸 때 꺼내서 다시 정함 (`cleanup-plan.md` 5절) |

## 7. 이 표를 만들며 찾은 것

1. **헌법 4조가 방향 A와 맞지 않음:** 4조는 "임시 정책 등록 → [승인]"을 정하고 있음. 방향 A에서는 논의 대상을 결정한 사람 이름으로 반영함. 헌법 개정이 먼저 필요함 (개정 절차도 같은 이유로 고침).
2. **다국어 흐름이 기존 규칙과 다름:** 7단계 흐름은 "AI로 7개 언어 언어셋 추가", 기존 `language-set.md`는 "Claude는 번역을 만들어내지 않음". F6을 쓸 때 정함.
3. **"정리해 보여 주고 확인받은 뒤 반영":** discussion-answer 3절의 이 순서가 방향 A "결정 반영"에 빠져 있었음. 논 문서를 쓸 때 넣음.
4. **겹치는 항목 찾기:** provisional-policy 6절의 "같은 정책을 바꾸는 항목 먼저 찾기"가 방향 A에 빠져 있었음. 논 문서를 쓸 때 넣음.
5. **부록 A 빈칸 찾기:** 케이스 2(신규) 요건 정의에 바로 쓸 수 있는 목록이라 버리지 않고 F1로 옮김.
