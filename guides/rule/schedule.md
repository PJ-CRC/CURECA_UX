# 일정

> 상태: 초안 v0.1 (2026-11-04). 정하지 않은 것은 5절에 모았습니다.

팀 일정은 Google 스프레드시트에서 관리합니다. 팀 프로그램의 일정/작업 > 일정 탭은 그 시트를 같은 모양으로 보여 주고, 탭에서 고친 것은 시트에 씁니다. 주간 진행 현황(`rules/weekly-status.md`)은 이 일정을 기준으로 셉니다.

## 1. 원본

- 원본은 스프레드시트 "1.CURECA-2026_Part2" › 2-2.WBS(간소)입니다.
- 일정 탭에서 담당자 · 상태 · 기간을 고치면 시트에 씁니다.
- 시트에서 직접 고친 것은 일정 탭의 [새로고침]을 누르면 바로 반영됩니다.

## 2. 줄 구성

| 칸 | 내용 |
| --- | --- |
| Part · 구분 | 차수와 버전 묶음 (예: 2.1 2차 · 2.1.1x, 모바일 · 2.2) |
| 플랫폼 | L-IOS, T-IOS, L/T 등 |
| 업무 | 업무(메뉴) 이름. 그 아래 `ㄴUI` 줄은 같은 업무의 UI 작업 |
| 담당자 | 업무 줄은 UX 담당자, `ㄴUI` 줄은 UI 담당자 |
| 상태 | 3절 |
| 기간 | 시작일 · 종료일 |
| 날짜 칸 | 기간에 맞춰 칠함 (4절) |

## 3. 상태값

미정 · 대기 · 진행 중 · 리뷰(예정) 중 · 디스크립션 작성 · 완료 중에서 고릅니다(2026-11-04 사용자 결정).

업무 한 건(업무 줄 + `ㄴUI` 줄)의 상태를 셀 때는 `rules/weekly-status.md` 3절을 따릅니다. UX가 완료여도 UI가 완료가 아니면 그 업무는 진행 중입니다.

## 4. 기간과 날짜 칸

- 일정 탭에서 기간 칸을 누르면 달력이 열리고, 시작일과 종료일을 고르면 날짜 칸이 자동으로 칠해집니다.
- 날짜 칸 색은 시트와 같습니다.

| 줄 | 색 |
| --- | --- |
| 업무 줄 (UX) | 초록 |
| `ㄴUI` 줄 | 노랑 |
| 상태가 진행 중인 줄 | 진한 초록 |

- 날짜 칸은 평일(월~금)만 있습니다. 오늘은 빨간 선으로 표시합니다.

## 5. 정할 것

1. 시트에 있는 "제외" 상태를 상태값에 둘지, 줄을 숨길지
2. 시트와 일정 탭에서 같은 줄을 동시에 고쳤을 때 어느 쪽을 따를지
3. 리뷰(예정) 중 · 디스크립션 작성을 언제 쓰는지 (상태값의 뜻)
