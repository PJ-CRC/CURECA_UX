## 바꾸는 내용

장비 통합 상태가 Running, Partial Running, Paused일 때 Door 잠금을 해제해 Module이 Paused가 된 뒤 사용자가 Door를 한 번도 열지 않으면, 그 Module은 Paused를 계속 유지함.

## 이유와 근거

- 고객이 아직 정의하지 않음. 8월 정책서의 "문을 한 번도 열지 않으면 Unlocked를 유지하다가 Run 시작 시 자동 잠금"은 Run 중 잠금 해제가 불가하던 때의 규칙이라 지금 경우를 다루지 않음
- 2026-11-02 사용자 결정: 정의될 때까지 Paused 유지로 진행
- 참고: Run Start를 하면 Unlocked인 Door는 자동으로 잠기고 Run이 진행됨 (POL-EQP-008 규칙 9)

## 적용한 화면
