# Claude 작업 지침 (진입점)

> 상태: 초안 v0.1 (2026-10-29).

이 파일은 Claude가 이 저장소에서 작업을 시작할 때 가장 먼저 읽는 파일입니다. 여기에는 무엇을 어떤 순서로 읽고 실행하는지만 두고, 상세 규칙은 `rules/` 아래 각 문서에 둡니다. 팀 프로그램, Claude Code, Claude 채팅 어느 경로로 작업하든 같은 규칙을 읽게 하기 위해서입니다.

## 작업 시작 순서

1. [rules/constitution.md](rules/constitution.md) — 헌법. 모든 룰과 작업에 우선합니다.
2. [rules/claude-work.md](rules/claude-work.md) — 작업 유형, 공통 순서, 보고 형식.
3. 요청을 작업 유형으로 분류하고, `rules/claude-work.md`의 공통 순서대로 진행합니다.

## 초안 단계 동안

- 지금은 룰을 만드는 단계라, `background/`의 두 문서를 작업 근거로 함께 씁니다.
- 결정되지 않은 내용은 만들어내지 않고 `background/worklist.md`에 질문으로 남깁니다.
