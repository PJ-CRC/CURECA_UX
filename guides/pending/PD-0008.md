# PD-0008 숫자 표기: 천 단위 쉼표, 소수 자리, 백분율

## 제안 내용

Common UX에 정의가 없는 숫자 표기 규칙을 정해 공통 정책으로 둡니다.

1. 천 단위 쉼표를 쓸지 (예: `1,000 ea` / `1000 ea`). 수량(ea · rxns), 금액(Cost Setting), 건수(Items 638)에 같게 쓸지
2. 소수 자리 (예: Error Rate, 사용량, 온도 · 부피처럼 소수가 나오는 값의 자리 수와 반올림 방식)
3. 백분율 표기 (`95%` / `95 %`, 소수 자리)
4. 언어별로 쉼표 · 마침표가 바뀌는지 (7개 언어 중 독일어 · 포르투갈어 · 스페인어 · 이탈리아어 · 프랑스어는 보통 `1.000,5`처럼 씀) 아니면 모든 언어에서 같은 형식을 쓸지

## 이유와 근거

- Common UX COMM-4-a(1/4)에는 날짜 · 시간만 있고 숫자 형식이 없음 (`common-ux/common-policy-candidates.md` 3절 7번)
- 기존 화면 디스크립션 180화면 중 표기 형식을 적은 화면이 36개뿐이고 화면마다 다름 (2026-11-04 분석, `rules/screen-spec.md` 8절)
- 수량 표기 `{수량} ea ({n} {단위})`는 COMM-4-b(5/5)에 있으나 쉼표 여부는 없음

## 영향 범위

- CID: 숫자가 나오는 화면 전체
