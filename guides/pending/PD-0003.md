# PD-0003 Total Sample·STAT Sample에 STAT Storage Sample을 셈하는 방법

| 항목 | 내용 |
| --- | --- |
| 상태 | 대기 |
| 대상 자료 | 정책서 (POL-SMP-008), 화면 디스크립션 (LI-QUK, LI-RUN-01, TI-INF-03-02) |
| 제안자 | 서보경 |
| 제안일 | 2026-11-02 |
| 긴급 | 아니오 |

## 제안 내용

Run 준비, Quick Start, Run Report에서 보여 주는 Sample 수를 어떻게 셈할지 정합니다.

- Total Sample에 STAT Storage로 넣은 Sample도 합치는지
- STAT Sample은 STAT Storage에 넣은 Sample 수인지, Trolley에 도킹된 Sample 중 응급 Sample 수인지
- 정한 뒤 세 화면의 디스크립션을 같은 말로 맞춤

## 이유와 근거

- LI-QUK 디스크립션 1: Total Sample "(트롤리에 도킹된) 검사 대상 총 검체 수", STAT Sample "(트롤리에 도킹된) 검사 대상 검체 중 응급 검체 수"
- LI-RUN-01 디스크립션 2: Run 대상은 Trolley 또는 응급 서랍(STAT Storage)으로 도킹된 Sample
- TI-INF-03-02 디스크립션 2-1: Samples Total "Trolley에 적재되어 검사된 전체 검체 수"
- POL-SMP-008: STAT Sample은 STAT Storage로 넣는 응급 Sample
- 2026-11-02 사용자: 팀원과 논의 (SM5)

## 영향 범위

- 정책 ID: POL-SMP-008 규칙 3
- CID: LI-QUK (반영 대기 목록 6), LI-RUN-01, TI-INF-03-02 (반영 대기 목록 11)
