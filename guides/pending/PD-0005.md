## 제안 내용

PCR 데이터가 있는 PCR Socket을 다시 스캔할 때 기존 데이터를 어떻게 다룰지 정합니다.

- 8월 정책서: PCR 전용 Socket은 사용자가 Socket을 인식(스캔)하는 시점에 기존 데이터가 리셋되고 새 정보로 갱신됨
- 담당자 적재 정책서와 지금 화면: PCR box가 있는 Socket을 다시 스캔하면 이어서 적재함 (예: 1세트를 넣고 나중에 다시 작업해 1세트를 더 넣음). 용도가 다를 때만 전환 컨펌(MS_Confirm_015·017)을 거침
- 사용자 의견(2026-11-03): 8월 문장은 지우는 쪽이 맞아 보이나, PCR Reagent는 1세트를 넣은 뒤 다시 작업할 수 있으므로 팀원과 내부 논의 후 정함

## 이유와 근거
