# PD-0004 Material Setup 스캔 화면의 [Next] 버튼

| 항목 | 내용 |

| 긴급 | 아니오 |

## 제안 내용

Material Setup의 첫 스캔 화면에서 [Next] 버튼을 뺄지 정합니다.

- 지금: 스캔하면 자동으로 다음 화면으로 넘어가고, 스캔 전에는 [Next]가 비활성이라 누를 일이 없음
- 디스크립션의 [Next] 설명도 "스캔 시 → (2-1)과 동일하게 변경 & 다음 화면으로 이동"이고 2-1 "Scan"은 내용이 없음
- (가) [Next]를 화면에서 뺌
- (나) [Next]를 두고 역할을 정함 (예: 자동 이동 대신 사용자가 눌러 넘어감)
