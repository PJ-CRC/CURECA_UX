## 제안 내용

화면의 버튼, 라벨, 메뉴, 입력 안내 문구의 대소문자 규칙을 하나로 정합니다.

- (가) Title Case: 단어마다 첫 글자 대문자 (예: Select All, Sign In, Trolley Name)
- (나) Sentence case: 첫 단어만 첫 글자 대문자 (예: Select all, Sign in, Trolley name)
- 입력 안내 문장 끝 마침표를 붙일지도 함께 정합니다 (예: Please enter a valid password / ... password.)
