# Common UX 후보 목록

> 상태: 초안 (2026-11-12). 올리는 법은 [candidate-rules.md](candidate-rules.md).

Common UX(가이드)에 컴포넌트가 없어서 화면에서 직접 그린 요소를 모은 목록입니다. 3단계에서 가이드에 없는 요소를 그릴 때 이 목록을 먼저 보고, 맞는 것이 있으면 가져다 씁니다(`flow/3-design.md` 공통 3 "Figma 그리기" 3번(`공통 3-3` 요소를 찾는 순서)).

- 이 목록에는 **5단계 완료 때만** 올립니다. 그래서 여기 있는 요소는 모두 완료된 화면에서 쓰인 것입니다.
- 줄은 지우지 않습니다. Common UX에 들어가거나 쓰지 않기로 하면 상태만 바꿉니다.
