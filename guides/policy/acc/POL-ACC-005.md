# POL-ACC-005 ID 조건

## 정의

없음

## 규칙

1. ID 길이는 4자 이상 32자 이하임.
2. 쓸 수 있는 문자는 영문 소문자(a-z), 숫자(0-9), 특수문자 _ - 임.
3. ID는 대소문자를 구분하지 않음. 대문자를 입력하면 소문자로 바꿔 저장함.
4. 이미 쓰고 있는 ID는 만들 수 없음.
