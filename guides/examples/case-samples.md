## 본보기에서 따르는 것

```
┌─ CID/Case ─────────────────────────────────────────────┐
│ [초록 띠] Case 1. Sample 상태별 데이터 노출 예시              │
│                                                        │
│   [노란 띠] 1-1. 검사 시작 후 Prep 장비에서 … 회수된 검체        │
│   • Run Start를 해서 상태 값은 변했지만 … 값은 미노출           │
│   (달라지는 부분만: 표 머리줄 + 해당 행 몇 줄)                  │
│                                                        │
│   [노란 띠] 1-2. 검사 진행 중 특정 단계에서 검사 실패한 검체       │
│   • Progress는 검사 실패한 단계 노출                         │
│   (해당 행)                                              │
│                                                        │
│ [초록 띠] Case 2. Progress 상태 정보 Tooltip                │
│   • 설명 한 줄                                            │
│   (툴팁이 뜬 부분만)                                       │
└────────────────────────────────────────────────────────┘
```

- 초록 띠 `Case n. 제목`, 노란 띠 `n-1. 조건`, 띠 아래 설명 한두 줄(개조식)
- 달라지는 부분만 잘라 그림. 화면 전체가 달라질 때만 전체
- 항목 · 컬럼은 지우지 않고 값만 '-', 버튼은 Disabled
- 순서가 있는 흐름은 장면을 옆으로 나란히 놓고 번호로 설명

## 본보기와 다르게 하는 것 (2026-11-10 정함)

| 본보기 | 새로 그릴 때 |
| --- | --- |
| 케이스마다 오른쪽에 작은 패널(Ver · Date · CID · 화면, Dev · SG) | 두지 않음. 버전은 본 화면을 따름 |
| 케이스 패널에 설명을 적은 곳이 있음 (Test Management Case 3) | 설명은 본 화면 디스크립션에 번호를 두고 적고, 케이스 조각에 그 번호 표시를 붙임 (LIS Setting 방식) |
| LIS Setting은 케이스를 본 화면 아래에 둠 | 늘 `CID/Case` 프레임에 모으고 기획 프레임 바로 아래에 둠 (우선 이 안, 테스트해 보고 확정) |
